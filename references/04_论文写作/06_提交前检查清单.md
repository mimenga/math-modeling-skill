# 提交前检查清单

逐项勾选，全部通过再提交。

## 摘要与论文

- [ ] 摘要单独成页、不超过一页、独立可读（不引用正文图表）
- [ ] 每个子问题在摘要中都有"方法 + 结果数值"
- [ ] 创新模型名/方法名在摘要中加粗；题目要求交付结果文件时，摘要已写明文件名（如"结果存于 result1.xlsx"）
- [ ] 论文结构完整：摘要→重述→假设→符号→模型→检验→评价→**AI 工具使用声明→参考文献**→附录（声明必须在参考文献之前，硬约束第 1 条）
- [ ] 需引用的公式均已编号且全文连续（(1)(2)(3)…，不按章节编号），公式后有逐符号解释，正文用"式(k)"回引
- [ ] 所有图表有编号和标题，正文有引用（图 1、表 2）；图注可自解释（携带关键情景参数）
- [ ] 结论部分有具体数值支撑，无空话套话
- [ ] 参考文献格式统一，正文有引用标注
- [ ] 全文无错别字、无口语化表达、无未完成占位符（TODO、xxx 等）

## 模型与结果

- [ ] 每个子问题有主模型 + 对比模型（对比模型注明选择/舍弃理由）
- [ ] 有交叉验证/留出验证的误差指标，且写进结果表专列（RMSE/R²/相对误差）
- [ ] 至少有 1 项灵敏度分析（配图或表；范式与结论句式见 `07_灵敏度分析与模型检验操作模板.md`）
- [ ] 迭代/搜索类算法附迭代过程表（含收敛方向）与收敛曲线
- [ ] 随机种子固定，结果可复现
- [ ] 模型假设与正文呼应，无孤立的假设

## 代码与文件

- [ ] 附录代码完整可运行（在干净环境跑一遍）
- [ ] 代码有必要的注释，数据文件路径说明清楚
- [ ] 输出文件命名规范（队号+题目号 或 竞赛要求的格式）
- [ ] 不包含临时文件、缓存、超大中间数据

## 提交格式（依据官方 2026 修订稿，逐条硬性核对）

- [ ] 正文不超过 30 页，无目录；页边距四周均 ≥2.5cm
- [ ] 页码从摘要专用页起、页脚中部、从 1 连续编号
- [ ] 电子版为单独一个文件（建议 PDF，或 Word），≤20MB，不压缩
- [ ] 电子版第一页为摘要专用页（承诺书、编号专用页不放入电子版）
- [ ] 电子版内容与纸质版（含附录）完全一致
- [ ] 附录含支撑材料文件列表 + 全部完整可运行源程序（没用程序则注明"本论文没有用到程序"）
- [ ] 支撑材料打包为单个 RAR/ZIP，≤20MB；不含承诺书/编号页；无支撑材料注明"本论文没有支撑材料"
- [ ] 全文（含支撑材料）无任何身份、学校、赛区信息
- [ ] MD5 流程正确（见 `01_参赛总纲/01_参赛关键信息与AI新规.md`：先交 MD5 后传文件，改文件必须重新生成 MD5）
- [ ] 截止时间前完成上传，预留 30 分钟缓冲
