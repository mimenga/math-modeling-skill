# 优化类问题（出现率最高之一）

## 精确求解（小规模、结构清晰）

| 模型 | 适用 | 工具 |
|---|---|---|
| 线性规划 LP | 目标约束全线性（生产、运输、配比） | `linprog` |
| 整数/0-1 规划 | 变量取整、选/不选（选址、指派、背包） | `intlinprog` |
| 混合整数规划 | 部分连续部分整数 | `intlinprog` |
| 指派问题 | 人-任务一对一 | 匈牙利算法 |
| 二次规划 QP | 目标含二次项 | `quadprog` |
| 非线性规划 | 目标/约束非线性 | `fmincon` |
| 多目标优化 | 多个冲突目标 | 线性加权/ε约束/NSGA-II |
| 目标规划 | 带优先级的多目标 | 偏差变量+序贯 |

## 启发式求解（大规模/组合爆炸）

| 算法 | 适用 | 特点 |
|---|---|---|
| 模拟退火 SA | TSP、调度 | 概率接受差解跳出局部最优 |
| 遗传算法 GA | 组合优化、背包、选址 | 种群进化，编码是关键 |
| 粒子群 PSO | 连续优化、参数寻优 | 实现简单收敛快 |
| 蚁群 ACO | TSP、路径 | 信息素正反馈 |
| 禁忌搜索 TS | 调度、布局 | 禁忌表防回跳 |
| 贪心/动态规划 | 有最优子结构 | 精确但需建模技巧 |

## 零平台破阵（高维随机优化保命技，2025A 实战验证）

目标函数存在大片零值平台（**遮蔽/命中/覆盖/拦截/连通类**目标极常见）时，随机初始化种群的适应度几乎全 0，差分进化/GA 的差分向量失去方向、退化为随机漂移——**这不是调参问题，是初始化策略错误**。

**先判零平台**：随机采样 1000 点算目标值，>95% 相同（如全 0）即触发本节。

**四步破阵**：
1. **解析/几何反演构造种子**：不去"撞"可行解，先指定想要的结果再反解参数。范例（2025A 遮蔽）：取目标遮蔽时刻 t*，在导弹-目标视线上按比例取点 P；云团下沉补偿 P_boom = P + (0,0,3δ)；水平约束 v = D/t_boom ∈ [70,140] **先解析解出 t_boom 的可行区间 [D/140, D/70] 再取点**（这步是关键，否则联合可行域窄到一个种子都生成不出）；竖直反解 Δt = √(2(z_uav−z_boom)/g) 并检查 t_drop ≥ 0。完整 worked example 见 `09_2025A题专题/01`。
2. **种子混入初始种群 5%~20%**，其余仍随机采样保多样性。
3. **单调性诊断**：资源更多的方案最优值 ≤ 资源更少的方案 ⇒ 必有维度未生效，逐维分解贡献定位（2025A 实测：Q2=Q3=Q4 同值 ⇒ 三枚弹两枚在"睡大觉"）。
4. **互验要报搜索强度**：DE+PSO 共享同一种子缺陷会一起陷入同一局部最优——互验一致 ≠ 全局最优，须附收敛曲线与搜索预算（实战：互验同停 4.7388 s，加强搜索后 4.8325 s）。

## 写法要点（高分关键）

1. **先写三要素**：决策变量、目标函数、约束条件——建模是评委重点。
2. 画流程图，讲清求解逻辑。
3. **做灵敏度分析**（参数 ±5%/±10%）——评委明确的高分点。
4. 用启发式必须写：动机（为什么精确法不可行）+ 算法流程 + 多实例测试 + 与近似/精确解对比。
