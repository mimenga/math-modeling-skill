# 回归分析（预测建模核心）

## 建模四步

1. 设定回归模型
2. 求系数（最小二乘，正规方程 (X'X)b=X'y）
3. 检验：F 检验（方程显著）、t 检验（系数显著）、残差分析、共线性诊断
4. 预测 + 置信区间

## 关键统计量

- **R²**=SSR/SST：y 变化由 x 解释的比例，越接近 1 越好；多元看修正 R²。
- **F 检验**：整个方程是否显著；**t 检验**：每个系数是否显著。
- **回归标准误差**：残差均方平方根，衡量估计精度。

## 残差分析（模型诊断）

- 残差 e=y-ŷ；残差图：随机散布=正常；**喇叭形=异方差**；**弯曲=非线性**（加高阶项或变换）。
- 正态性：残差直方图、P-P/Q-Q 图。

## 自变量筛选

- 前进法（空模型逐个引入）；后退法（全模型逐个删除）；**逐步回归（最常用，进出结合）**。

## 多重共线性

- **VIFⱼ = 1/(1-Rⱼ²)**，VIF>10 视为严重共线性。
- 处理：剔除相关变量 / 逐步回归 / 岭回归 / 偏最小二乘。

## 回归在数模竞赛中的注意点

1. 分类自变量先转**哑变量**；
2. 先相关分析确认线性，再回归；
3. 输出：回归方程 + R² + F/p + 各系数 t/p + 残差诊断图，缺一不可；
4. 预测时自变量取值应在观测范围内（外推有风险）；
5. 因变量二值 → 用**逻辑回归**而非线性回归。

## 完整流程模板（food.sav 案例）

```
描述统计 → 相关分析（r 与 p 值）→ 全模型回归（方程+R²+F）
→ 残差分析（直方图+P-P 图）→ 逐步回归（重要变量排序）
→ 结论（各系数业务解读）
```

## 价格弹性与 log-log 回归（C 题定价类标配）

- **模型**：log(销量) = β₀ + β₁·log(价格) + 控制项，**β₁ 就是价格弹性**（价格变 1%，销量变 β₁%），天然无量纲、正文可直接引用；
- 形态对比：销量-价格关系不确定时，**log-log / 线性 / 二次**三形态按修正 R² 或 AIC 选优（呼应"相关性勿只做线性"法则，禁只跑线性）；
- **必报**：β₁ + 标准误 + t + p + R²，缺一不可（同上方"输出"要求）；
- 细节：销量/价格为 0 的行先剔除（或 +1 平移）再取对数；价格数据要按"单品-日期"去重聚合口径写清楚；
- **进阶（内生性 2SLS / 分位数回归）**：见 `06_内生性工具变量与分位数回归.md`；代码见 `scripts/12_C题定价补货专题.py` 的 `elasticity_regression()`。
