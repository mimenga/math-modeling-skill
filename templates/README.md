# 论文模板使用说明

本文件夹包含两套可用的国赛论文模板（均已对齐官方 2026 修订稿：**电子版第一页为摘要专用页、正文不要目录、全文匿名**）。

## 一、Word 模板（推荐新手/快速上手）
文件：`国赛论文模板_Word.docx`
- 已设置 A4 页面、页边距 2.5cm、宋体小四正文、黑体标题、页码从摘要页起页脚居中、页眉队伍编号；
- 结构：摘要专用页 → 问题重述与分析 → 假设与符号 → 数据预处理 → 逐问建立与求解 → 评价改进推广 → AI 声明 → 参考文献 → 附录，无目录、无自制封面（匿名要求）；
- 内置**三线表样式**（顶线/底线 1.5 磅、表头下线 0.75 磅、无竖线），符号说明表与结果示例表已套用；
- 内置**公式编号占位段**（居中公式 + 右侧 (1)(2) 连续编号），用法：打开 → 按【】提示替换内容 → 公式用 **MathType** 输入 → 图表编号后插入。

## 二、LaTeX 模板（推荐公式多/追求排版质量）
文件夹：`LaTeX模板/`
- `main.tex` 完整可编译（XeLaTeX），含摘要专用页、三线表（booktabs）、算法伪代码、双图并排示例、参考文献、AI 声明、附录代码；
- 公式为 `equation` 环境**全文自动连续编号**，正文用 `式~\eqref{eq:xxx}` 回引；
- 环境要求：TeX Live 或 MikTeX（Windows）；
- 编译命令：`xelatex main.tex`（跑两遍以更新交叉引用）；
- 公式排版质量高，适合 A/B 题这种公式多的题。

## 三、两套模板的写作要点（必须遵守）
1. **摘要最后写**，占评分 20-25%，必须含"每问方法 + 具体数字结果"；
2. 假设 3-5 条，每条带理由；
3. 符号说明用**三线表**，全文符号统一；
4. 每问 = 模型建立 + 求解 + 结果分析，分开写；
5. **灵敏度分析（±5%/±10%）是国奖标志性步骤，必须有**（范式见 `references/04_论文写作/07` 卡）；
6. 代码放**附录**，不放正文；
7. 参考文献 GB/T 7714 格式，正文标注；
8. **公式编号全文连续 (1)(2)(3)…**，不按章节编号，正文用"式(k)"回引；
9. **AI 工具使用声明必须保留在参考文献前**（2026 新规）。

## 四、如何生成自己的版本
- Word 版由 `make_word_template.py` 生成（python-docx），想改结构可改脚本重新生成；
- LaTeX 版直接改 `main.tex`。
