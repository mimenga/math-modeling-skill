# 06 · 赛前两周冲刺计划（9/1 - 9/9）

> ⚠️ 年度性信息：本卡日期按 2026 赛季倒排，换年需按当年开赛日重排（见 `00_当前赛况配置.md` 换年更新清单第 3 项）。

> 距开赛约两周时启用本卡。两周内你们要完成三件大事：
> ① **一次完整模拟赛**（9/3-9/6，性价比最高）；
> ② **论文模板 + 代码库**（9/7 前就绪）；
> ③ **团队磨合 + 选题预演**（9/8-9/9 收尾）。

---

```
第一周（9/1-9/7）：知识补漏 + 模拟赛 + 工具就绪

9/7 周一 20:00：报名截止（确认！）
9/10 周四 18:00：开赛
```

## 二、第一周：9/1（周二）— 9/7（周一）

### 9/1（周二）准备日
- 全队开会 1 小时：确认分工（见 `03_三人分工与AI协作.md`）、确定模拟赛题目、分配任务；
- 编程手：整理代码库清单，列出缺什么补什么；
- 写作手：开始搭论文模板（封面、摘要格式、章节结构、三线表、参考文献格式）；
- 建模手：过一遍 `02_建模方法库/00_方法选择决策树.md`，圈出自己最不熟的 3 类方法，安排补学。

### 9/2（周三）工具就绪日
- 三人各自确认电脑环境：Python（numpy/pandas/sklearn/matplotlib/scipy/statsmodels）+ MATLAB/SPSS；
- 装好 AI 工具（DeepSeek/ChatGPT/Claude 等），跑 2 个测试（一个代码题、一个润色题）确认可用；
- 建共享文档：题目拆解模板、进度表、素材库；
- 论文模板初版完成（写作手牵头）。

### 9/3-9/6（周四-周日）⭐ 完整模拟赛（最重要！）
- **严格模拟**：9/3 18:00 开题 → 9/6 20:00 提交，完全按真实时间线（参考 `02_四天三夜时间线.md`）；
- 题目选择：2024C（农作物种植）或 2023C（蔬菜定价）——题型与你们目标一致；
- **全程执行**：选题限时 1 小时、每天对表、写作从 D2 开始、D4 练提交流程；
- **模拟赛目的不是拿满分，而是暴露问题**：时间分配、写作卡点、代码 bug、协作冲突，全部记下来；
- 模拟赛结束当晚：全队复盘 1 小时，写"问题清单 + 改进措施"。

### 9/7（周一）复盘 + 报名确认日
- **上午**：确认报名状态（9/7 20:00 截止！联系学校教务处确认已报名、名单正确）；
- 下午：模拟赛复盘会（哪些环节超时？哪些模型没跑通？写作哪里卡？）；
- 晚上：按复盘结果补漏：补代码库缺的模块、改进论文模板、优化分工。

## 三、第二周：9/8（周二）— 9/9（周三）轻量收尾

> **关键原则：这周不再学新东西，只做"熟"和"稳"。**

### 9/8（周二）
- 三人一起精读 2 篇 2023/2024 年 C 题国奖论文（mcm.edu.cn 下载），重点看：
  - 摘要怎么写（方法+数字）；
  - 每问的模型选择与衔接；
  - 灵敏度分析、模型评价怎么写；
- 对照你们的论文模板，调整结构。

### 9/9（周三）最后准备日
- 全队过一遍 `08_比赛物资与提交清单.md`，**逐项打勾**；
- 打印/收藏：`02_四天三夜时间线`、`03_三人分工与AI协作`、`04_论文写作/01_评分权重与拿分策略`；
- 模拟赛复盘的问题清单再过一遍，确认每项都有对策；
- 晚上 22:00 前休息，开赛前一晚睡好。

## 四、两周内的知识补漏优先级（按你们自测结果）

| 优先级 | 内容 | 怎么补（每天 1-2 小时即可） |
|---|---|---|
| P0 | 论文写作（摘要/结构） | 精读 2 篇获奖论文 + 用自己模板各写 1 页 |
| P0 | 模拟赛 | 9/3-9/6 全程 |
| P1 | 时间序列（ARIMA/灰色） | 补代码：statsmodels 跑通 ARIMA 预测示例 |
| P1 | 非线性回归（样条/多项式） | 补代码：numpy polyfit / scipy 样条拟合 |
| P1 | 灵敏度分析 | 学 1 个案例怎么算（参数 ±5%/±10% 重跑） |
| P2 | 随机森林/XGBoost | 跑通 sklearn 示例（分类+回归各 1 个） |
| P2 | 遗传算法/模拟退火 | 用现成代码库跑 1 个优化示例即可 |
| P2 | 图论（Dijkstra/Floyd） | 有现成代码即可，不用深究 |
| P3 | 微分方程/数值计算 | 仅 A 题备选需要，C 题可跳过 |

## 五、心态准备（比赛能不能发挥好的关键）

1. **获奖有偶然性，但实力决定下限**：你们已具备省奖实力，冲国奖靠"论文完整度+细节+创新点"；
2. **允许不完美**：比赛中必然有做不出来的问，降级处理，别内耗；
3. **团队信任**：相信分工，别互相抢活；队长拍板后全队执行；
4. **作息优先**：前两天休息好 = 最后一天效率高；
5. **过程>结果**：一次完整的建模历练对保研/考研/科研的价值远大于一张证书。
