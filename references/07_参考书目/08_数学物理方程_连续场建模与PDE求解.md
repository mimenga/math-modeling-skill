# 《数学物理方程简明教程》(张鲁明、王姗姗 编) 建模方法总结

> **书目定位**：数学物理方程（PDE）入门教材，聚焦三大经典方程——**波动方程（双曲型）、热传导方程（抛物型）、Laplace/位势方程（椭圆型）**的导出、定解问题与求解方法。对数学建模的价值：当问题涉及**空间分布与时间演化的连续场**（温度场、浓度扩散、振动传播、静电场、流体场）时，PDE 是标准建模语言；本书提供分离变量法、积分变换法、Green 函数法等求解工具。未被照片划定，但为"连续介质建模"的基石。

## 二、三大典型方程的建模推导（第1章核心方法）

### 1. 弦振动方程（一维波动方程）——微元法建模范式
$$u_{tt} = a^2 u_{xx} + f(x,t), \quad a^2 = \frac{T}{\rho}$$

**推导过程（微元法四步，竞赛写论文可直接模仿）**：
1. 取微元 $ds \approx dx$（微小振动假设 $u_x \ll 1$）；
2. 受力分析：张力沿切线方向，横向合力 $T(\sin\alpha' - \sin\alpha) \approx T u_x$ 的变化；
3. 牛顿第二定律 $F=ma$：$\rho dx\, u_{tt} = T \Delta u_x + f_0 dx$；
4. 令 $\Delta x \to 0$（取极限）得 PDE。

> 关键点：**建模假设决定了方程形式**（柔软、均匀、细弦、微小振动四个假设缺一不可）；符号"$\approx$"在极限中变为"="——这就是"从物理到数学"的标准动作。

### 2. 热传导方程（抛物型）——守恒律建模范式
$$u_t = a^2 \Delta u + f, \quad a^2 = \frac{K}{c\rho}$$

**推导逻辑**：能量守恒——温度升高所需热量 = 边界流入热量 + 内部热源。
- Fourier 实验定律（热流正比于温度梯度）：$q = -K \nabla u$；
- 流入热量用 **Gauss 公式**化为体积分（散度定理）：$div(K\nabla u)$；
- 得守恒方程 $c\rho u_t = div(K\nabla u) + \rho f_0$。

> 关键点：**"变化率 = 通量散度 + 源项"** 是扩散/热传导/流体的通用守恒形式。浓度扩散（Fick 定律）、渗流、传染病空间传播都长这样。

### 3. 位势方程（Laplace/Poisson，椭圆型）
- 热传导达到稳态（$u_t=0$）→ Poisson 方程 $\Delta u = -f$；无源 → Laplace 方程 $\Delta u = 0$。
- 也可由静电场导出（$E=-\nabla u$，Gauss 定理）。
- **意义**：稳态/平衡状态的场分布；调和函数描述无源场。

### 4. 定解条件（三类边界条件——竞赛建模必须写全）
| 名称 | 形式 | 物理意义 |
|---|---|---|
| 第一类 Dirichlet | $u|_{\partial\Omega}=\mu$ | 边界函数值已知（温度、位移） |
| 第二类 Neumann | $\frac{\partial u}{\partial n}\big|_{\partial\Omega}=\mu$ | 边界通量/流量已知（绝热=0） |
| 第三类 Robin | $(\frac{\partial u}{\partial n}+hu)|_{\partial\Omega}=\mu$ | 边界与外界热交换（弹性支撑） |

- 初值条件（$t=0$ 时的函数值与导数值）+ 边界条件 = 定解条件。
- **适定性**（存在性+唯一性+稳定性）：解连续依赖于定解资料——**微小输入误差只引起微小输出变化，模型才可用**（与《0数学模型》的"强健性"思想一致）。

## 三、求解方法武器库

### 1. 分类（第2章）：先识别再求解
- 判别式 $\Delta = b^2 - ac$：>0 双曲型（波动类，有实特征线）；=0 抛物型（热传导类）；<0 椭圆型（位势类）。
- 特征线法化简：特征方程 $a(dy/dx)^2 - 2b(dy/dx) + c = 0$。
- **建模启示**：拿到 PDE 先分类——双曲/抛物/椭圆对应完全不同的求解套路与性态。

### 2. 分离变量法（第3章，最核心）
- **思想**：设 $u(x,t) = X(x)T(t)$，代入方程 → 得两个 ODE（时间部分+空间部分），由边界条件确定空间本征值问题（Sturm-Liouville 问题），解为**本征函数的级数叠加**。
- 步骤：设分离变量解 → 求本征值与本征函数 → 叠加 → 用初始条件定系数（Fourier 级数展开）。
- 适用：矩形/圆形区域、齐次边界；非齐次可叠加特解或本征函数展开。
- 圆域/球域 → 引出 **Bessel 函数**（圆域径向）、**Legendre 多项式**（球域角向）。

### 3. 积分变换法（第4章）
- **Fourier 变换**（对空间变量）：把偏导变乘法、把 PDE 变 ODE；适用于**无界区域**初值问题。
- **Laplace 变换**（对时间变量）：处理含时间的初值问题（与《2常微分方程》第5章衔接）。
- 步骤：变换 → 解代数/ODE → 反演（查变换表）。

### 4. 波动方程的通解法（第5章）
- **达朗贝尔公式**：$u(x,t) = \frac12[\phi(x-at)+\phi(x+at)] + \frac{1}{2a}\int_{x-at}^{x+at}\psi(s)ds$——行波分解。
- **依赖区间/决定区域/影响区域**：扰动传播的因果结构（信息以速度 $a$ 传播）。
- **Huygens 原理**：三维波的清晰前沿（无后效）。

### 5. 椭圆型方程的 Green 函数法（第6章）
- **δ函数**：点源（点电荷、点热源、冲击）的数学描述——**点源响应**思想的基石。
- **基本解**：点源产生的场。
- **Green 函数**：边界条件下的点源响应；**叠加原理**：任意源产生的场 = 对源密度与 Green 函数的积分。
- 意义：**"先求点源响应，再积分叠加"**是线性场论建模的通用思想（也用于积分方程、反问题）。

## 四、建模启示总结

1. **连续场问题 → PDE**：温度场、浓度场、振动、电磁、流体、种群空间扩散——先写守恒律/牛顿定律/实验定律。
2. **建模四要素写全**：方程（机理）+ 初始条件 + 边界条件（类型要判断正确）+ 适定性说明。
3. **守恒律模板**：$\partial_t u = div(D\nabla u) + f$（扩散）；$\partial_{tt} u = c^2\Delta u$（波动）；$\Delta u = -f$（稳态）。
4. **先分类再求解**：双曲（特征线/达朗贝尔）、抛物（Fourier/分离变量）、椭圆（Green/分离变量）。
5. **分离变量法是首选**：有界区域、规则边界用它；无界区域用积分变换；点源问题用 Green 函数。
6. **本征值（谱）思想**：分离变量暴露系统固有频率/本征函数——物理意义（驻波、共振）可用于解释。
7. **数值求解兜底**：复杂区域/非线性 PDE 用差分法/有限元（衔接《5数值计算方法2006》第9章）。
8. **适定性=模型可用性**：论文中说明"解对数据的连续依赖"，体现理论严谨性。
