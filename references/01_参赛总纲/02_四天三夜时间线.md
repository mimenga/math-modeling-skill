# 四天三夜时间线（74 小时作战计划）

> ⚠️ 年度性信息：具体日期以 `00_当前赛况配置.md` 为准；时间线结构与节奏建议跨年通用。

> 原则：前两天保效率、留休息；后一天保质量、防慌乱。不提倡无意义通宵。

## 三大里程碑

```
里程碑1（D1 24:00）：定题 + 数据摸清 + 全部问建模框架确定 + 最简模型跑通
里程碑2（D2 24:00）：所有问模型求解完成 + 论文初稿 60%
里程碑3（D3 24:00）：全问求解收尾 + 论文初稿 80% + 摘要第一版（提交动作全部在 D4）
```

## Day 1（周四 18:00-24:00）定题与框架

| 时间 | 任务 |
|---|---|
| 18:00-18:30 | 下载题目，通读全部题目 |
| 18:30-19:00 | **选题讨论**（每人 5 分钟读题+表态，队长拍板） |
| 19:00-20:00 | 精读逐句拆解，每问写"一句话任务" |
| 20:00-22:00 | 编程手数据侦查 / 写作手+建模手文献调研（AI 辅助） |
| 22:00-23:30 | 画解题流程图，确定每问主模型+对比模型+假设 |
| 23:30-24:00 | 跑通问 1 最简模型 |

**D1 铁律**：选题 1 小时内定，不许回头；24:00 前必须有一个模型跑出数字。

## Day 2（周五）模型攻坚

- 上午：问 1 完善 + 问 2 框架搭建
- 下午：问 2/3 建立求解；写作手同步写重述+假设+数据预处理
- 晚上：问 3/4 求解；多模型对比；写作手完成 60% 初稿

**D2 铁律**：写作手从 D2 上午就写，**别等模型全好**；每完成一问立即存数字/图/公式。

## Day 3（周六）求解收尾 + 成稿

- 上午：攻克剩余问 + 灵敏度分析开始
- 下午：全问求解完成；写作手完成 80% 初稿
- 晚上：灵敏度 + 评价章节；摘要出第一版；全队通读标注

**D3 铁律**：D3 24:00 前初稿必须 80%；某问做不出就**降级处理**（简化假设/给部分结果），绝不让论文缺一块。

## Day 4（周日）打磨与提交（最关键 12 小时）

| 时间 | 任务 |
|---|---|
| 8:00-10:00 | 精雕摘要（方法+数字，1 页内）+ 关键词 |
| 10:00-12:00 | 全队逐段通读，查逻辑/公式/图表编号/数据一致性 |
| 13:30-16:00 | 格式大检查；补参考文献、附录代码；**生成 MD5** |
| 16:00-18:00 | 最终校对；写 AI 声明+详情 |
| 18:00-19:30 | 全文终检；**提交 MD5 控制码**（官方 20:00 截止，留余量），确认回执 |
| 19:30-20:30 | 休息等待上传窗口（官方约 20:30 起才开放上传实体文件） |
| 20:30 起 | 上传论文 PDF+支撑材料；检查提交成功回执并截图留证 |

**D4 铁律（提交细节，年年有人栽）**：
1. 20:00 前提交 MD5（改过文件 MD5 就变，必须重生成）；
2. 上传窗口别拖，提前 2-3 小时搞定；
3. 只有第一位学生能提交，确认账号密码；
4. 上传后立刻打开确认完整可读；
5. 论文必须含 AI 工具使用声明。

## 精力管理（被低估的胜负手）

- 每天午休 1-1.5h（雷打不动）；D1/D2 晚最晚 1 点睡；
- D3 晚可通宵 1 人值守（写作手），D4 上午全员头脑清醒最重要；
- 每 2-3h 起身 5 分钟；清淡饮食，备巧克力/坚果。

## 应急方案

| 崩点 | 对策 |
|---|---|
| 模型三天没跑通 | 降级：最简单模型 + 完整写作（普通模型写清楚也能获奖） |
| 数据有问题 | 记录处理方式、论文说明理由；**不伪造数据** |
| 写不完 | 保证：摘要 + 每问模型建立 + 结果，这三块必写 |
| 网络/系统故障 | 提前 3h 提交；U 盘备份；联系教务处 |
