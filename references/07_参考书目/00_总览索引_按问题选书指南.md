## 二、按问题类型快速选书指南

### 1. 动态/演化过程建模（随时间变化的系统）
| 数据/模型特征 | 用哪本书 | 用什么 |
|---|---|---|
| 数据按天/月/年离散记录 | 02 差分方程 / 07 差分手册 | 递推模型、特征根法、稳定性判据 |
| 连续变化、需解析分析 | 03 常微分方程 | Malthus/Logistic、捕食模型、Liapunov 稳定性 |
| 空间分布+时间演化（场） | 08 数学物理方程 | 波动/热传导/位势方程、分离变量法 |
| 有现成 ODE 但解不出 | 05 数值计算方法 | 欧拉法、**Runge-Kutta（RK4）** |

## 三、竞赛 74 小时通用打法（对应书目）

1. **读懂题目、确定模型类型**（01 数学模型：建模步骤与分类）
2. **建立基本模型**：
   - 动态问题 → 差分/微分方程（02、03）或 PDE（08）
   - 优化问题 → 规划/运筹（04、06）
   - 数据问题 → 统计/机器学习（10、12）
3. **求解模型**：
   - 解析/数值求解 → 数值计算方法（05）
   - 大规模优化 → 智能算法（09）
   - 试验寻优 → 试验设计（11）
4. **模型分析**：稳定性（02、03）、灵敏度（04 对偶/影子价格）、误差分析（05、11）
5. **检验与写论文**：结果验证、图表呈现、误差讨论

## 四、各书一句话精华

- **01 数学模型**：建模七步 + 机理/测试两种方法 + "先简单后改进"。
- **02 差分方程**：离散数据用递推，特征根定稳定，ODE/PDE 的简化版。
- **03 常微分方程**：守恒律写方程，平衡点+Liapunov 做定性分析。
- **04 运筹学**：优化问题 = 决策变量 + 约束 + 目标，工具箱全在这。
- **05 数值计算**：插值/拟合/数值积分微分/RK4，只有数据也能算。
- **06 随机规划**：不确定参数 → 期望值/机会约束/相关机会三大模型。
- **07 差分手册**：差分方程的公式速查表，查完即用。
- **08 数学物理方程**：连续场问题 → 三类 PDE + 分离变量/积分变换/Green 函数。
- **09 智能优化**：算不出来的优化问题，GA/PSO/SA/ACO 兜底求满意解。
- **10 应用统计**：拿数据先探索，再推断、回归、分类、降维、时序。
- **11 试验设计**：多因素多水平寻优 → 正交/均匀设计 + 方差/回归分析。
- **12 机器学习**：数据驱动建模的系统方法库，分类/回归/聚类/深度学习。
