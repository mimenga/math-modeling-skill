# NIPT 四问完整可执行解法方案

> 核心临床规则：检测时点越早终止妊娠风险越小；但太早 Y 浓度不达标（<4%）检测无效。个体差异大（随机效应主导）、有测量误差、有多次检测样本。

## 问题 1：Y 浓度与孕周、BMI 关系（4 步）

1. **轻量清洗**：只删明显错误/空缺；多次检测样本用混合效应模型天然处理。
2. **相关性分析**（先判线性/非线性）：Pearson r 与 Spearman ρ 都算；|Spearman| 明显 > |Pearson| → 非线性。
3. **建立关系模型**（三选一，推荐都做对比）：
   - 二次多项式回归 Y=β₀+β₁GA+β₂GA²+ε
   - **自然样条回归**（评委推荐）
   - **线性混合效应模型 LMM**（获奖解法）：`mixedlm("Y ~ GA + BMI + GA*BMI", groups=孕妇ID)`
4. **显著性检验 + 呈现**：t 检验、F 检验、p 值；R²（LMM 分条件/边际）；按 BMI 分 3 组画散点+拟合曲线。

**写作**：不要只给"多元线性回归"；说明为什么选非线性（残差图/相关系数对比）。

## 问题 2：按 BMI 分组 + 最佳时点

**核心权衡**：早检测→风险小但浓度可能不达标；晚检测→达标率高但风险大。最优时点 = "达标概率"与"早发现收益"的最优折中。

4 步：
1. **BMI 分组（差异性指标切分，不用聚类）**：BMI 排序后找切分点使组间 Y 浓度/达标概率差异最大 → **贪心切分算法**；简单替代：按分位数试切（如 <30.5 / 30.5-36 / >36）再验证组间差异显著（ANOVA/卡方）。
2. **刻画达标概率**：定义"达标"=Y≥4%；每组拟合 P(达标|孕周) 用逻辑回归。
3. **构造风险目标**：风险函数 R(w)（w 越小风险越小，如 R(w)=1-e^(-kw)）；目标 `min R(w) s.t. P(w)≥α`（α 取 90%/95%）或 min 期望风险。
4. **结果 + 敏感性**：表（BMI 组|区间|最佳时点 w*|达标率|风险）；α 从 0.85→0.95、R(w) 参数 ±10% 看 w* 稳定性；画每组"风险-时点"曲线标最优点。

**写作**：明确分组机制、风险指标定义式、目标函数；自证"为什么不用聚类"（聚类仅依据数据相似性，未考虑孕周协变量与优化目标）。

## 问题 3：多因素优化（方案 A 推荐）

**方案 A（获奖解法）**：Cox 比例风险模型——把"达标"当事件、孕周当时间轴；`h(w|X)=h₀(w)·exp(β·X)`，X=(BMI组,身高,体重,年龄)；得各组达标风险随时间变化 → 推 P(w)。
**方案 B（易实现）**：多变量逻辑回归 P(达标|w,BMI,身高,体重,年龄) 加交互项，再按 BMI 分组求各时点达标率。

**写作**：强调与问 2 递进关系（"问题 3 引入身高体重年龄协变量，通过 Cox 回归纳入达标概率建模"）；对比问 2/3 最优时点差异；敏感性照旧。

## 问题 4：女胎异常判定（5 步，核心创新）

1. **质控筛选**：总读段数、比对率、重复率剔除低质量样本。
2. **差异性分析**（写进论文）：对每个指标做正常 vs 异常 t 检验/Mann-Whitney U + 效应量/箱线图 → 选区分度大的指标。
3. **分档建模**：按测序质量分优/中/差三档，分别定阈值（低质量档阈值更保守）。
4. **双阈值三区判定**：高阈值（0.995 置信）≥ → 判异常；两阈值间 → 灰区建议复检；< 低阈值（0.99）→ 正常。阈值由正常样本分布（均值+k·标准差）或分位数定，说明临床依据。
5. **优良性分析**：混淆矩阵、灵敏度、特异度、假阳性率、假阴性率；讨论"假阳性可复检、假阴性会漏诊"的代价权衡；ROC/AUC。

**写作**：差异性分析表格（指标|正常均值|异常均值|p|是否显著）是评分点；判定规则一条条写清楚；说明与"普通 ML 分类"的区别。
