# 2025A 实战复盘：零平台失效与分配证伪

> 来源：队伍实战逆向检查报告蒸馏（2026-09-09；引文、几何、数值经二次核实）｜ 关键词：零平台、解析种子、单调性诊断、分配对照实验、互验局限

## 一、失败一：随机初始化全军覆没（最严重，答案错误级）

**现象**：Q2/Q3/Q4 最优值完全相同（4.738828 s），FY2/FY4 贡献恒 0。

**诊断三步法（可直接复用到任何"资源递增型"题目）**：
1. **单调性检查**：允许更多弹/机的问，最优值反而 ≤ 资源更少的问 ⇒ 多出的维度必有未生效者（额外弹只会让遮蔽并集不减，相等即贡献为 0）；
2. **随机搜索 vs 构造种子对比**：随机数千次最好 0.92 s，解析构造的种子一上来 ~4.76 s——差距 5 倍说明不是调参问题，是初始化策略错误；
3. **逐维贡献分解**：定位贡献为 0 的弹/机，确认是优化失败而非几何不可行。

**修复**：几何反演构造解析种子（通用四步法已沉淀至 `02_建模方法库/01_优化类问题.md` 零平台破阵节）。FY2→M1 从恒 0 → 5.04 s，FY4 → 4.93 s。

**边界**：FY1→M2/M3 种子为 0 属**真实几何限制**（FY1 在 y=0 平面、M2/M3 视线偏 ±600 m），不要当 bug 修。

## 二、失败二：分配策略拍脑袋，被对照实验证伪

原假设"每架 3 枚分打 M1/M2/M3，分散收益可加"——理论论证方向正确（同弹并集有重叠、异弹直接相加），但只有定性论述。4 种方案同强度对比后，"偏 M2"方案 2:0 全胜分散：

| 无人机 | 分散 (M1,M2,M3) | 偏M2 (M1,M2,M2) |
|---|---|---|
| FY3 | 6.7088 | **10.8040**（+61%） |

**教训**：方案选择要有证明或对照实验（对标 2023B 国一"先数学证明布设方案是最佳"）；三枚导弹来向相近、遮蔽窗口时间重叠时，集中打易覆盖导弹优于机械分散；但指派必须受可行性表约束（FY1 打 M2/M3 无可行解，强制分散导致整架失效）。

**遗留风险**：按验证过的分配重跑后 Q5 仍有提升空间；且 M3 被完全放弃——见下。

## 三、关键更正：M3 不是"几何不可覆盖"

种子表证明 FY2/3/4/5→M3 均有可行种子（911/4821/1013/230 颗，最佳单弹 4.20/4.98/3.99/3.97 s）。**"专项分析 M3 几何可覆盖性"是个伪问题——它可覆盖，Q5 的 M3=0 是指派+零平台伪影**（M3 方向的维度没喂解析种子）。题目明确要求干扰三枚导弹，交付物完全放弃 M3 有实质评分风险。

## 四、失败三：互验一致 ≠ 全局最优

DE 与 PSO 一致收敛到 4.7388 s，加大搜索强度后 DE 达 4.8325 s——两算法共享同一种子缺陷时会**一起陷入同一个局部最优**。正确姿势：互验 + 报告搜索预算/种群规模/收敛曲线；互验值若能被更强搜索改进，必须更新结论。

## 五、有价值的"负发现"（照实写进论文，评委认这个）

- **灵敏度**：云团有效期 20 s 完全不敏感（本场景遮蔽窗口远短于有效期）；导弹速度最敏感（−10% 速度 → +49% 时长，几何直觉：视线扫过云团更久）；g 极敏感（−10% → 遮蔽完全消失）——说明给定策略的解处于临界状态，引信标定精度是实际应用瓶颈。
- **数值误差**：粗采样只影响区间定位、端点二分细化（容差 1e-5）兜底精度——Δt 从 0.05 缩到 0.001，结果极差仅 3×10⁻⁶ s。
