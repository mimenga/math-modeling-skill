# 预测类问题（C 题重灾区）

## 回归家族（Y 连续）

| 方法 | 适用 | 要点 |
|---|---|---|
| 多元线性回归 | 线性关系 | 检验共线性（VIF）、残差分析 |
| 多项式/样条回归 | 非线性趋势 | **评阅要点提醒：多元线性不够，要非线性** |
| 岭/套索回归 | 高维、共线性 | L1/L2 正则化 |
| 混合效应模型 | 重复测量、个体差异 | 随机截距/斜率（NIPT 获奖解法） |
| 广义线性模型 | 计数/0-1 型 Y | 逻辑回归、泊松回归 |

## 时间序列（按时间顺序）

| 方法 | 适用 | 要点 |
|---|---|---|
| 移动平均/指数平滑 | 短期、趋势平缓 | 最简单基线 |
| ARIMA | 平稳化后自回归+滑动平均 | 差分定阶（ACF/PACF） |
| 季节性分解 | 有周期 | STL/X11 |
| 灰色预测 GM(1,1) | 小样本、指数趋势 | 数据要光滑，短期预测 |
| Prophet | 强趋势+季节性 | 上手快 |
| LSTM | 长时序非线性 | 数据量大才用 |

## 机器学习预测

| 方法 | 适用 | 要点 |
|---|---|---|
| 决策树回归 | 非线性、可解释 | CART |
| 随机森林 | 稳健、抗过拟合 | 特征重要性输出 |
| XGBoost/LightGBM | 表格数据预测之王 | 先做基线再调参；作主模型须配特征重要性/SHAP 解释并与经典模型对比（评委对黑箱主模型反感，见 `05/05_速查卡`） |
| SVR | 小样本非线性 | 核函数选择 |
| 神经网络 | 大样本复杂关系 | 慎用（数据少易过拟合） |

## 预测题标准写法

```
训练/测试划分（留出法或 k 折交叉验证）
  → 误差指标（RMSE/MAE/MAPE）
  → 多模型对比
  → 选优
  → 画预测曲线
```

**要点**：先做相关性分析判线性/非线性（|Spearman| 明显 > |Pearson| → 非线性 → 用多项式/样条）；混合效应模型处理同一对象多次观测；固定随机种子。
