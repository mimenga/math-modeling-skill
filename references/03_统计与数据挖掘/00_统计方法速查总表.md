# 统计方法速查总表（竞赛必用）

> 核心逻辑：**无论做什么，先跑 EDA（缺失/异常/分布/关系），再选方法。**

## 第一步：看变量类型选方法

| 你的问题 | 变量类型 | 首选方法 |
|---|---|---|
| 一个连续变量的分布？ | 连续 | 直方图、箱线图 + 描述统计 |
| 一个分类变量的构成？ | 定类/定序 | 频数表、条形图、饼图 |
| 两个连续变量有无线性关系？ | 连续×连续 | Pearson 相关 + 散点图 |
| 两变量相关，怀疑有第三者作祟？ | 连续×连续 | **偏相关分析** |
| 两个定序变量相关？ | 定序×定序 | Spearman / Kendall |
| 两个定类变量是否独立？ | 定类×定类 | 列联分析（χ² 检验） |
| 二分类 × 连续（两组比较）？ | 定类(2组)×连续 | 独立样本 t 检验 |
| 同一对象前后两次测量？ | 配对×连续 | 配对样本 t 检验 |
| 多组（≥3）连续差异？ | 定类(多组)×连续 | 单因素方差分析 + LSD/S-N-K |
| 两个分类因素 × 连续？ | 双因素×连续 | 双因素方差分析（含交互） |
| 连续因变量与多个自变量？ | 混合×连续 | 多元线性回归（逐步） |
| 价格对销量/需求的影响（定价题）？ | 连续×连续 | log-log 弹性回归；因果结论上 2SLS/分位数（→ `06_内生性工具变量与分位数回归`） |
| 二分类因变量预测？ | 混合×二值 | 逻辑回归 |
| 预测精度不够？ | 任意 | 决策树/随机森林/XGBoost/集成 |
| 没有标签找天然分组？ | 任意 | K-Means / 系统聚类 |
| 随时间变化的数据？ | 时间序列 | ARIMA / 灰色预测 / LSTM |

## 第二步：变量类型与适用分析（务必记牢）

| 变量类型 | 用什么分析 |
|---|---|
| 离散定量型、连续定量型之间 | **相关分析** |
| 定性（品质）型变量之间 | **列联分析** |
| 连续定量型 vs 二值离散变量 | **假设检验**（t 检验） |
| 连续定量型 vs 多值/多变量离散变量 | **方差分析** |

## 第三步：论文呈现规范

每个统计结论都给出**检验统计量 + p 值**。按"目的 → 数据 → 方法 → 结果（表格+图）→ 结论"组织。

## 数据类型（基本概念）

- **定类（名义）**：性别、职业（无顺序）→ 频数、列联
- **定序（顺序）**：一等/二等/三等 → 频数、Spearman/Kendall
- **定距/定比（数值）**：身高、销售额 → 均值、方差、相关、回归
- **截面数据**：同一时点；**时间序列**：不同时点；**纵向/面板**：同一对象多次观测（用广义线性模型/混合效应）
