# 《数值计算方法》(魏毅强、张建国、张洪斌 等编) 建模方法总结

> **书目定位**：当模型"只有数据、没有解析式"时，这本书就是工具库。照片明确标注重点：**第5章代数插值（Lagrange/Newton/分段线性/Hermite/样条插值——数学原理、如何选择）、第6章数据拟合与函数逼近（最小二乘）、第7章数值微分与数值积分（只有数据时如何计算）、第8章常微分方程数值解法（8.2 Runge-Kutta法——数学原理、如何实现）**。

## 一、数值计算的基本思想（第1章）

- **计算过程**：实际问题 → 数学模型 → 计算方法 → 程序设计 → 上机计算。数值计算研究"模型到算法"这一环。
- **误差理论**：截断误差（方法误差）、舍入误差（计算机字长）；误差传播分析。
- **算法设计原则**：避免两个相近数相减、避免大数吃小数、防止溢出、控制计算次序。
- **数值方法的四个要求**：面向计算机、有可靠理论分析（收敛性+数值稳定性）、计算复杂性好、经数值实验验证。

> 建模启示：竞赛中几乎所有模型最终都要"数值化"——学会把连续问题离散化并控制误差，是结果可信的保证。

## 二、第5章 代数插值（照片标注重点①）

**问题**：已知 $n+1$ 个数据点 $(x_i, y_i)$，构造多项式通过所有点，用于近似未知中间值。

| 方法 | 形式 | 特点/适用 |
|---|---|---|
| **Lagrange 插值** | $L_n(x)=\sum y_i l_i(x)$，$l_i$ 为基函数 | 形式对称、公式化；适合编程实现；节点增多要全部重算 |
| **Newton 插值** | 差商表递推构造 | 增加节点时只需追加一项（递推增量）；适合逐步加密 |
| **Hermite 插值** | 同时满足函数值与导数值 | 已知导数信息（如速度、斜率）时使用 |
| **分段线性插值** | 相邻点间线性连接 | 简单、稳定，但折线不光滑；数据点多时效果好 |
| **三次样条插值** | 分段三次多项式，节点处二阶连续 | **光滑性好、数值稳定**；数据密集且需要光滑曲线时的首选 |

**如何选择（照片强调的"数学原理、如何选择"）**：
- 数据点少、需精确过点 → Lagrange/Newton（高次多项式，注意 Runge 现象——高次插值在端点剧烈振荡）。
- 已知导数信息 → Hermite。
- 数据多、不要求光滑 → 分段线性。
- 数据多、要求光滑美观 → 三次样条（竞赛画图、插补数据的常用方法）。

**反插值**：已知 $y$ 求 $x$（交换变量插值）。

## 三、第6章 数据拟合与函数逼近（照片标注重点②）

**问题**：数据带误差（不必过每个点），找一条"最贴近"的曲线——**最小二乘拟合**。

- **最小二乘原理**：$\min \sum_{i=1}^n [y_i - f(x_i)]^2$。
- **多项式拟合**：设 $f(x)=a_0+a_1x+\dots+a_mx^m$，对 $a_j$ 求偏导 → 正规方程组（法方程）→ 解出系数。
- **超定方程组的最小二乘解**：$A^TAx = A^Tb$（方程组数>未知数时的最佳近似解）。
- **一般最小二乘拟合**：线性化技巧——指数 $y=ae^{bx}$（取对数）、幂函数 $y=ax^b$（取对数）、双曲函数等可化为线性；无法线性化的用非线性回归（Gauss-Newton、Levenberg-Marquardt）。
- **最佳平方逼近**：连续情形下用正交多项式（Legendre）逼近函数。

**如何选择**：先画散点图判断趋势 → 选择拟合函数类型（线性/多项式/指数/对数/幂）→ 最小二乘求参数 → 看拟合优度（残差、$R^2$）→ 必要时升阶或换模型。**拟合（数据驱动）与插值（精确过点）的选择：数据有误差→拟合；数据精确且要过点→插值。**

## 四、第7章 数值积分与数值微分（照片标注重点③："只有数据时如何计算"）

### 数值积分
- **基本思想**：用插值多项式代替被积函数再积分（插值型求积公式）。
- **Newton-Cotes 公式**：梯形公式（1次）、Simpson 公式（2次）、Cotes 公式——代数精度逐步提高。
- **复合求积公式**：分小区间再用梯形/Simpson——提高精度（区间细分）。
- **Romberg（龙贝格）算法**：梯形公式外推加速——逐次折半+Richardson 外推，精度高。
- **Gauss 公式**：节点+权重联合优化，代数精度最高（2n+1 次）。
- **应用**：只有离散数据点（无解析式）时求曲线下面积、期望、定积分——竞赛中由数据表算总量（如积分求累计收益）。

### 数值微分
- **差商公式**：前差、后差、中心差商 $f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}$（精度最高）；插值型求导公式。
- **应用**：数据表中"只有离散点，没有函数表达式"时计算变化率、速度、加速度、边际值。

## 五、第8章 常微分方程数值解法（照片标注重点④）

**问题**：初值问题 $y'=f(x,y), y(x_0)=y_0$ 无解析解 → 在一系列点上求近似值。

- **8.1 Euler 法（欧拉法）**：$y_{n+1}=y_n+hf(x_n,y_n)$——最简单的一步法（折线法）；误差 $O(h)$；改进的 Euler（梯形公式预测-校正）误差 $O(h^2)$。
- **8.2 Runge-Kutta 法（龙格-库塔法）★照片重点**：
  - **思想**：用区间内多个点的斜率加权平均代替平均斜率，提高精度。
  - **二阶 RK（中点法/Heun法）**：误差 $O(h^2)$。
  - **四阶 RK（经典 RK4）**：$y_{n+1}=y_n+\frac{h}{6}(k_1+2k_2+2k_3+k_4)$，误差 $O(h^4)$——**竞赛数值模拟事实标准，务必会实现**。
- **8.3 Adams 方法（多步法）**：用前面多步的信息，精度高但需起步。
- **8.5 方程组与高阶方程**：高阶化为一阶方程组统一用 RK。
- **8.6 边值问题数值解**：打靶法、差分法。

**如何实现（照片强调）**：选定步长 $h$ → 初始化 → RK4 递推 → 收敛性检查（减半步长对比）。注意步长选择：太小计算量大，太大误差大/不稳定。

## 七、建模启示总结

1. **插值 vs 拟合的选择**：精确数据过点→插值（数据少用 Lagrange/Newton、数据多用样条）；带噪声数据→最小二乘拟合。
2. **只有离散数据时**：数值积分算总量、数值微分算变化率、插值补中间点——"数据驱动的计算"三件套。
3. **ODE 数值解**：竞赛中动态模型没有解析解时，RK4 是默认求解器；会用、会写、会验证收敛。
4. **算法要检验**：收敛性、稳定性、误差分析、数值实验——论文的"模型求解与验证"部分体现严谨性。
5. **误差意识**：注意步长、精度、舍入误差对结果的影响。
