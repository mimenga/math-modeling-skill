# 聚类、关联、动态与仿真

## 聚类

| 方法 | 适用 | 要点 |
|---|---|---|
| K-means | 大样本球形簇 | 定 k（肘部法/轮廓系数） |
| 层次聚类 | 小样本 | 画树状图 |
| DBSCAN | 任意形状+噪声 | 密度聚类 |
| 高斯混合 GMM | 概率聚类 | EM 求解 |
| 谱聚类 | 图结构 | 拉普拉斯特征分解 |

**⚠️ 2025C 评阅要点明确说"直接聚类不是好的分组方法"**——当分组是为后续优化服务时，要考虑**机制合理性**（如按风险差异切分），而不是简单聚类。

## 关联规则

- **Apriori / FP-growth**：支持度、置信度、提升度。适用组合购买、特征组合推荐。

## 动态/微分方程（A 题主力）

| 模型 | 适用 |
|---|---|
| Malthus/Logistic 增长 | 人口、生物量 |
| SIR/SIS 传染病 | 传播动力学 |
| Lotka-Volterra | 生态捕食 |
| 热传导/波动/位势方程 | 物理场 |
| 差分方程 | 离散时间动态 |
| 排队论 | 服务系统 |

数值解法：ODE 用 `ode45`/RK4；PDE 用有限差分（显式/隐式+追赶法）。

## 仿真

- **蒙特卡罗**：随机抽样估计，比赛"必用方法"——可用于检验模型正确性。
- **元胞自动机**：空间动态（交通流、疏散、传染病空间传播）。
- **Agent 建模**：个体交互涌现（高阶加分项）。

## 数据预处理工具箱（每题的必经之路）

1. **缺失值**：删除 / 均值中位数插补 / 回归插补 / 多重插补（说清理由）
2. **异常值**：3σ / 箱线图 IQR / 业务规则（**医学数据异常值要谨慎——可能是真实病例！**）
3. **标准化/归一化**：Z-score / Min-Max（距离类算法必做）
4. **特征工程**：哑变量、衍生变量（BMI 式组合）、对数变换、交互项
5. **降维**：PCA、因子分析、Lasso 特征选择
6. **数据划分**：训练/验证/测试（或 k 折），固定随机种子

**⚠️ 别为清洗而清洗**：评阅注 1 说 NIPT 数据"除几个空缺和输错外无需清洗删补"。预处理要服务于解决问题，不要为展示工作量做无意义操作。
