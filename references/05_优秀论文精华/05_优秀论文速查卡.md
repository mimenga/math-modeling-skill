# 05 优秀论文速查卡
### ——一页纸记住国奖论文的所有要点

---

## 一、结构速查（12 个模块）

```
摘要（逐问：方法+算法+数字结果）
 → 问题重述 → 问题分析（类型/难点/思路）
 → 模型假设（带理由） → 符号说明（表格）
 → 数据处理（数据特征观察！） 
 → 模型建立与求解（每问：准备→建模→算法→求解→检验）
 → 模型检验（误差/对照） → 灵敏度分析
 → 模型评价（优点/缺点/改进/推广）
 → AI 工具使用声明（★参考文献之前，硬约束★）
 → 参考文献 + 附录（程序、大表）
```

---

## 二、逻辑主线速查（一句话公式）

```
【数据线索/物理规律/文献结论】→【推断结构】→【选择模型】→【算法求解】→【检验误差】→【灵敏度】
```

**铁律**：模型出现前必须有"线索"；每个结论必须带数字。

---

## 三、图表规范速查

| 项目 | 规范 |
|------|------|
| 表 | 三线表；表题在**表上方**居中 |
| 图 | 图题在**图下方**居中；坐标轴有名称单位 |
| 密度 | 平均每页 ≥0.5 个图表 |
| 解读 | 每图后写"从图中可以看出…" |
| 引用 | 正文先"如图X所示/见表X"再出现图表 |
| 大表 | 移附录，正文留精简版 |

---

## 四、检验与灵敏度清单

- [ ] 误差指标：R² / MRE / 相对误差 / 误差限，至少其一
- [ ] 反验：用已知数据或文献数据验证模型
- [ ] 灵敏度：关键参数 ±5% 与 ±10% 扰动（硬约束口径）观察结果变化
- [ ] 稳定性：加噪声 / 换区间 / 换算法对比

---

## 五、经典模型工具箱（替代机器学习）

| 需求 | 模型 |
|------|------|
| 拟合预测 | 多项式/指数/对数拟合、差分方程、灰色 GM(1,1) |
| 动态机理 | 常/偏微分方程、传热学、运动学 |
| 几何 | 坐标变换、向量、三角推导 |
| 优化 | 线性/非线性规划、动态规划、遗传/模拟退火 |
| 评价 | AHP、熵权、TOPSIS、灰色关联 |
| 排队流 | 排队论、元胞自动机、Monte Carlo |

---

## 六、禁用与慎用

- ❌ 神经网络 / 随机森林 / XGBoost 作为主模型（不可解释、评审反感）
- ❌ 模型凭空出现（无线索）
- ❌ 空洞评价（"效果良好"）
- ✅ 经典方法为主线，ML 仅作对照（且说明为何不如经典方法）

## 七、摘要句式模板（背下来）

> 针对问题一，**观察数据发现**……，**因此建立**……模型，利用……算法求解，**得到**……，通过……检验，**误差为**……。

---

## 八、评分视角提醒

评阅人在 10 分钟内读完你的论文，ta 想看到：
1. **摘要**：逻辑通顺、数字详实 → 10 秒定印象
2. **问题分析**：思路清晰、敢于定性 → 确认你有建模思想
3. **模型**：有依据、有推导、可复现 → 验证功底
4. **图表**：规范、有解读 → 验证严谨与工作量
5. **检验**：误差、灵敏度 → 验证可信度
6. **评价**：真诚的优缺点 → 验证认知深度
