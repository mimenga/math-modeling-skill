# 02 图表设计与美观规范
### ——优秀论文的图表为什么"看起来很专业"

> 数据事实（基于抽样统计）：2015A1 全文 40 页含 20 幅图、11 张表；2017A 29 页含 35 幅图、6 张表；2018A 28 页含 20 幅图、4 张表；2016C 20 页含 21 张表。**国奖论文平均每 1–2 页就有一幅图或一张表。**

---

## 一、图表在评分中的隐性作用

评阅人在有限时间内通读全文，**图表是信息密度最高的载体**。一篇"图文并茂"的论文：
- 评阅人扫图就能理解建模思路，不需要逐字读公式；
- 图表展示了工作量（你画了多少图=你算了多少东西）；
- 规范的图表暗示了作者的严谨程度。

国奖论文的图表密度（每页图/表数）几乎是恒定规律：**正文每页至少 0.5 个图表元素**。

---

## 二、优秀论文图表的五大规范

### 1. 三线表（国赛硬性规范）
所有统计表都采用三线表格式——只有顶线、栏目线、底线三条横线，没有竖线、没有其他横线。2016C 的 21 张表全部是三线表。

```
───────────────  （顶线）
| 电流强度 | T剩=f(U-9) |
───────────────  （栏目线）
| 20A  | 0.9298(U-9)²+0.0818(U-9)-0.0087 |
| 30A  | 0.6205(U-9)²+0.0584(U-9)-0.0190 |
───────────────  （底线）
```

**表标题规范**：表序号 + 表名，置于**表上方**居中，如"表1 给定电流下，电池剩余时间随电压变化的关系"。

### 2. 图的标题与标注
**图标题置于图下方居中**，如"图1 黄金分割法上下界点、左右探测点图示"。这与表的标题位置相反，是国赛固定格式。

### 3. 坐标轴完整
所有函数关系图都标注坐标轴名称与单位（如"北京时间 / 差值"、"X轴 / Y轴 / Z轴"），曲线有图例（"实际影长 / 位置1影长 / 位置2影长"）。2015A1 的差值对比图在轴上明确标了单位（×10⁻³）。

### 4. 示意图与结果图分工明确
- **示意图**（建模思路、几何关系、物理过程）：说明模型建立的思想。2018A 画了"细杆示意图""热传导实例示意图"；2017A 画了"圆形厚度求解示意图""黄金分割法图示"。
- **结果图**（拟合曲线、温度分布、误差曲线）：展示求解结果与检验。2016C 把 9 条电流放电曲线实测值（黑线）与拟合值（黄线）叠画，直观展示拟合质量。

### 5. 流程图（算法可视化）
凡有算法步骤的论文，几乎都配流程图。2015A1 问题四的图像处理流程、2017A 的算法流程均有流程图。**流程图让算法逻辑"一图胜千言"。**

## 三、优秀论文图表类型清单（可直接套用）

| 场景 | 用什么图 | 范例 |
|------|---------|------|
| 数据趋势展示 | 折线图（多曲线叠加对比） | 2016C 九条放电曲线实测 vs 拟合 |
| 模型结果对比 | 误差曲线、拟合度图 | 2015A1 实际影长与求解影长差值曲线 |
| 几何关系说明 | 示意图（手绘风格/标注角度） | 2017A 圆形厚度求解示意图 |
| 物理过程描述 | 结构示意图 | 2018A 四层服装结构图 |
| 算法流程 | 流程图 | 2015A1 图像处理流程图 |
| 地理位置结果 | 地图标记图 | 2015A1 附录2/3 地理位置方位图 |
| 大规模数据结果 | 三线表（放正文）+ 完整表（放附录） | 2016C 表1–表6 |
| 参数敏感性 | 参数-结果折线图 | 2015A1 影长随各参数变化图 |
| 温度场/空间分布 | 热力图/三维图 | 2018A 温度场空间分布 |

## 四、"看图说话"：图表必须配解读文字

优秀论文从不会"只放图不解释"。每张图后面紧跟 1–3 句解读：

- "从图中可以看出，9 条曲线的拟合度 R² 都高达 0.9999"（2016C）
- "图中 9 条曲线的尾端表示电池刚开始放电瞬间的状态，经过一小段时间后趋于稳定放电状态，因此我们在建模时删除前 10% 的数据"（2016C）——**连删除数据都从图中找到依据！**

这就是"数据线索驱动"在图表层面的体现：**图表不仅是展示结果的装饰，更是论证过程的证据。**

## 五、具体操作规范（写给写作时的自己）

1. **图表编号**：全文按"图1、图2…""表1、表2…"分别连续编号，正文中**先引用后出现**。
2. **每幅图/表在正文都有引用**："如图 X 所示""见表 X"。
3. **表格数据对齐**：数字右对齐，文字左对齐，统一保留有效数字位数（2016C 统一 4 位小数）。
4. **配色克制**：2–3 种颜色即可（如黑/黄对比），避免花哨。国奖论文多用黑白或简单配色——**清晰比好看更重要**。
5. **字号统一**：图内文字不小于正文的 6 号，保证缩印后仍可读。
6. **大表格放附录**：超过半页的表格移到附录，正文只放精简版。2015A1 把 21 组影长数据放附录 1，正文只给摘要表。

## 六、图表自查清单

- [ ] 图表密度是否达标（平均每页 ≥0.5 个）？
- [ ] 所有表是否三线表？表题在表上方、图题在图下方？
- [ ] 坐标轴是否有名称和单位？
- [ ] 每张图后是否有"从图中可以看出…"的解读？
- [ ] 正文是否在图表出现前引用了它（"如图 X 所示"）？
- [ ] 数据有效位数是否统一？
- [ ] 大表是否已移到附录，正文只留精简版？
- [ ] 流程图是否覆盖了所有核心算法？
