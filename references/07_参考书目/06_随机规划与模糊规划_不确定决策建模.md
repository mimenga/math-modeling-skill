# 《随机规划与模糊规划》(刘宝碇、赵瑞清 编著) 建模方法总结

> **书目定位**：当优化问题中**参数不确定（随机/模糊）**时，本书提供统一框架——"不确定规划"：**期望值模型、机会约束规划、相关机会规划**三大模型族 + 求解工具（随机模拟、模糊模拟、遗传算法）。照片明确标注重点：**第4章期望值模型、第5章机会约束规划、第6章机会约束规划的应用**。核心流程图：**实际问题 → 随机规划模型 → 求解方法（随机模拟，或转为确定性模型）**。

---

## 一、为什么需要不确定规划

- 现实中很多决策在**观测到随机参数实现之前**就要做出（如明天需求未知，今天就要订货）。
- 经典确定性规划（LP/NLP）假设参数已知，直接套用会把不确定性"忽略"，导致最优解实际无法执行。
- 描述不确定性的两类量：**随机变量**（随机现象）与**模糊集**（模糊现象）；含这两类参数的规划分别叫**随机规划**和**模糊规划**，统称**不确定规划**。

### 三大模型族（本书理论主线）
1. **期望值模型（EV模型）**：取期望把随机问题化为确定性优化——"平均意义下的最优"。
2. **机会约束规划（CCP）**：允许决策在不利情况下不满足约束，但要求**约束成立的概率 ≥ 置信水平 α**——"大概率可行"。
3. **相关机会规划（DCP）**：不假定可行集确定，最大化"事件发生的机会函数"——"尽量使目标事件发生"。

## 二、第4章 期望值模型（照片标注重点①）

**思想**：把目标函数和约束中的随机参数用**数学期望**代替，转化为确定性规划。

- **期望值算子**：$E[\xi]$（随机变量期望）。
- **模型形式**：
  - 单目标：$\max E[f(x,\xi)]$，s.t. $E[g_j(x,\xi)] \le 0$。
  - 期望值多目标、期望值目标规划（引入偏差变量）。
- **凸性**：在一定条件下模型保持凸性（便于求解）。
- **补偿模型（两阶段）**：先作决策，随机参数实现后按实际情况补偿/修正——"决策-观察-补偿"两阶段结构。
- **求解**：① 期望可解析计算时化为确定性 LP/NLP；② 期望不可解析（多重积分）→ **基于随机模拟的遗传算法**。

> 建模启示：需求、价格、产量等不确定时，**先取期望（平均情形）建模**是第一步；期望模型是"最自然、最先尝试"的处理方式。

## 三、第5章 机会约束规划（照片标注重点②）

**思想（Charnes & Cooper 提出）**：决策必须在随机参数实现之前做出；允许约束不满足，但要求**约束成立的概率不小于置信水平 α**。

- **模型形式**：
  - $\max \bar f$，s.t. $Pr\{f(x,\xi) \ge \bar f\} \ge \beta$（目标机会约束）；
  - $Pr\{g_j(x,\xi) \le 0\} \ge \alpha_j$（约束机会约束）。
- **确定性等价类**：特殊情况（如 $\xi$ 正态、约束线性）可**转化为等价的确定性模型**——这是最理想的情形（照片标注"转为确定性模型"）：
  - 例：$Pr\{\sum a_i x_i \le b\} \ge \alpha$，$b$ 正态 → 等价于 $\sum a_i x_i \le E[b] + z_\alpha \sqrt{Var(b)}$（分位数形式）。
- **一些性质**：可行集凸性、单调性等。
- **求解**：无法转确定性等价时 → **随机模拟**（Monte Carlo 估计概率）+ **遗传算法**寻优。
- **机会约束多目标规划 / 机会约束目标规划**：推广形式。

> 建模启示：**"大概率可行""置信水平"**（如可靠性、服务水平、风险控制）是机会约束的典型应用场景——库存缺货率、投资风险约束、电力供应可靠性等。

## 四、第6章 机会约束规划的应用（照片标注重点③）

五个经典应用问题（建模范例，可直接套用）：
1. **生产过程**：随机需求的产量/库存决策。
2. **饲料混合问题**：营养成分随机波动时，保证达标概率 ≥ α 的最小成本配方。
3. **随机资源分配**：资源量随机时的分配方案。
4. **开放存储网络**：随机需求的网络库存配置。
5. **资金预算**：项目收益不确定时的投资组合选择（概率约束下的资本预算）。

> 应用建模流程（本书反复演示）：**实际问题 → 识别随机参数 → 选择模型类型（期望/机会约束）→ 建数学模型 → 随机模拟或转化确定性模型 → 遗传算法求解 → 数值例子验证**。

## 五、求解工具（第2、3章）

### 遗传算法（GA）（第2章）
- 模拟自然进化：染色体编码（二进制/浮点向量）→ 初始种群 → 适应度评价 → **选择**（适应度越高入选概率越大）→ **交叉** → **变异**（保持多样性、跳出局部最优）→ 迭代至终止。
- 优点：全局搜索、不要求函数光滑可导、对约束处理灵活；缺点：耗时。
- **处理约束**：删等式约束（变量替换）、设计可行染色体、惩罚函数。
- 适用于：多峰、搜索空间不规则、传统方法无法处理的优化问题。

### 随机模拟 / 模糊模拟（第3章）
- **随机数的产生**：均匀分布 → 逆变换法/舍选法生成任意分布随机数。
- **随机模拟（Monte Carlo）**：大量抽样估计期望值 $E[f(x,\xi)] \approx \frac1N\sum f(x,\xi_i)$、概率 $Pr\{g(x,\xi)\le0\} \approx \frac{满足次数}{N}$。
- **模糊集合理论**：隶属函数、可能性测度；**模糊模拟**估计模糊机会函数。
- 作用：期望、概率、机会函数无法解析计算时的标准估计手段（大数定律保证收敛）。

## 六、模糊规划（第9-12章，简介）

- **模糊机会约束规划**：模糊约束成立的可能性 ≥ α（Luhandjula、Liu & Iwamura）；有**清晰等价类**情形。
- **模糊相关机会规划**：模糊环境下最大化事件机会函数。
- **带模糊决策的模糊规划**：最优解本身是模糊集（而非清晰向量）。
- **Maximax（乐观模型） vs Minimax（悲观模型）**：极大化可能最大收益 vs 极大化可能最小收益——风险态度决定模型选择。

## 七、建模启示总结

1. **识别不确定性来源**：需求、价格、供给、产出、故障等参数带随机性时，确定性模型会失真。
2. **三步选择模型**：①目标要"平均最优"→期望值模型；②约束要"大概率满足"→机会约束规划；③要"事件尽量发生"→相关机会规划。
3. **优先找确定性等价类**：正态、线性、可分离情形下机会约束可化为普通 LP——求解简单、结果可解释，竞赛中优先做。
4. **不行就随机模拟+遗传算法**：通用兜底方案（Monte Carlo 估计 + GA 寻优）。
5. **置信水平 α 的选取**：α 是决策者风险偏好的体现，论文中可做 α 的灵敏度分析（加分项）。
6. **两阶段（补偿）思想**：先决策后补偿适合"先定计划、再根据实际调整"的赛题。
