# 03 模型选择依据与创新性
### ——"我们从数据中发现了什么线索，才用了这个模型"（重点专题）

> 这是整份分析里最重要的一份。评阅专家评审时最看重：**你的模型是不是"长"在题目和数据上的**——即模型的引入必须有可追溯的依据（数据特征、物理规律、文献结论），而不是生搬硬套。
>
> 用户特别要求：**在使用某个数学模型前，必须指出在题目给定/自己收集的数据中发现了什么线索，才导致了选择该模型；同时强烈不建议使用机器学习方法。** 本文件将用 8 篇国奖论文逐篇展示这条逻辑链的写法。

---

## 一、模型选择逻辑的通用公式

优秀论文中，每个模型的引入都符合下面的三段式：

```
【线索】我们在数据/题目/文献中观察到 X 特征
   ↓
【推断】这个特征暗示了 Y 结构（线性？二次？指数？守恒？几何关系？）
   ↓
【选择】因此采用 Z 模型（Z 恰好能刻画 Y 结构）
```

**写进论文的句式模板**：
> "观察附件数据发现……，由此可知……，**因此**建立……模型。"
> "由附件 1 可知介质吸收率恒为 1，故积分式可化简为 M=kh，**所以**接收数据与穿透厚度成正比，**进而**可用……求解。"

## 二、8 篇论文的"线索 → 模型"逐篇拆解

### ① 2015A 太阳影子定位：物理规律驱动

| 环节 | 内容 |
|------|------|
| **线索** | 影长由太阳高度角、方位角、赤纬角、时角共同决定；题目给的是影子顶点坐标（x,y）序列 |
| **推断** | 影长与杆高、太阳高度角存在确定的三角关系；多个时刻可列出多个方程 |
| **模型** | 影长变化机理模型（天文几何公式链）；问题二/三转为"超定方程组 + 最小二乘目标"的单/双目标优化模型 |
| **创新点** | ①用误差传递公式给出影长相对误差限 0.23%（分析性检验）；②问题三引入"影长斜率角之差"作为第二目标，解决仅靠影长无法同时定经纬度和日期的欠定问题；③问题四把图像处理（Canny 边缘检测+透视变换）与优化模型结合 |

**论文中的原话逻辑**："以影长差值平方和最小为目标函数，运用拟牛顿迭代法对模型进行求解"——为什么是最小二乘？因为 21 个方程、2 个未知数构成超定方程组，**超定方程组的最小二乘解是天然的模型选择**，论文先交代了"得到含有 21 个方程式的超定方程组"，模型选择顺理成章。

### ② 2016C 电池剩余放电时间：数据特征驱动（最典型的"线索→模型"范例）

| 环节 | 内容 |
|------|------|
| **线索1** | 附件 1 给出 9 条不同电流下的放电曲线，先画图观察：曲线尾端有一段"钝化"（刚开始放电瞬间的非稳定段） |
| **推断** | 钝化段不参与建模，删除前 10% 数据后，剩余曲线形态规则 |
| **模型1** | 对 9 条曲线分别做二次多项式拟合（y = a·x²+b·x+c，x=U-Um），R² 全部达到 0.9999 以上 |
| **线索2** | 拟合出 9 组系数 (a,b,c) 后，观察系数随电流 I 的变化规律 → **"我们发现，当电流 I 取对数 log 时，二次项系数、一次项系数和常数项系数均同 log(I) 呈线性关系，拟合度均超过 95%"** |
| **推断** | 系数随 log(I) 线性 → 可以把 9 个离散模型统一成一个含电流的二维模型 |
| **模型2** | 以 log(I) 为自变量拟合系数函数，得到"放电时间随电压和电流同时变化"的统一数学模型，可预测 20–100A 任意电流 |
| **创新点** | ①对数变换发现规律（数据挖掘式的建模智慧，但用的是经典拟合而非机器学习）；②删除钝化段的数据预处理有图像依据；③MRE 严格按题目定义计算（231 样本点），检验严谨 |

**这是全篇最精彩的逻辑链**：先拟合（模型1）→ 从拟合系数中再发现规律（线索2）→ 提升为统一模型（模型2）。模型不是拍脑袋选的，是**从数据里长出来的**。

### ③ 2017A CT 系统参数标定：物理定律 + 几何驱动

| 环节 | 内容 |
|------|------|
| **线索** | 朗伯贝尔吸收定律：衰减后能量与厚度为积分关系；**附件 1 中"有介质的地方吸收率全为 1"** |
| **推断** | 积分式化简为 M = k·h，**接收数据与穿透厚度成正比**（把复杂积分关系变成线性） |
| **模型** | 探测器间距：几何勾股定理 + 黄金分割搜索；旋转中心：两条中心线交点（几何）；180 个方向：Radon 变换 + 单目标优化（遍历夹角使误差平方和最小）；图像重建：中心切片定理 + 滤波反投影 |
| **创新点** | ①全部模型建立在"数据成正比"的化简之上，逻辑闭环；②自建"正方形+圆形"新模板改进标定精度；③稳定性分析：给数据加噪声看参数波动（很高级的检验） |

### ④ 2018A 高温作业服装：物理机理驱动（PDE 建模的标杆）

| 环节 | 内容 |
|------|------|
| **线索1** | 附件 2 温度数据显示：皮肤外侧温度 1000s 内指数上升到 47℃，之后基本稳定在 48℃ |
| **推断** | 温度最终稳定 → 假人体内是恒温 37℃ 的"耗散源"，热源与皮肤间达到动态平衡 → 边界条件类型确定 |
| **线索2** | 文献结论：空气层厚度 ≤6.4mm 时对流可忽略；37℃ 温差下辐射传热远小于传导 |
| **推断** | 只考虑热传导 → 用 Fourier 定律 + 能量守恒建立一维热传导 PDE |
| **模型** | 四层介质的一维热传导偏微分方程组 + 定解条件（初始、衔接、边界）+ 有限差分（后向欧拉）数值求解 |
| **创新点** | ①从实测温度"看出"动态平衡并反标定热交换系数 δ；②问题二用黄金分割法搜索最优厚度（避免盲目穷举）；③问题三把 (d₂,d₄) 看作平面点集遍历 + 厚度最小原则筛选（多目标处理智慧） |

### ⑤ 2019C 机场出租车决策：系统模拟 + 优化驱动

| 环节 | 内容 |
|------|------|
| **线索** | 司机决策受确定因素（等待时间、收益）与随机因素（航班数、车流量）共同影响 |
| **推断** | 随机因素无法解析刻画 → 用计算机模拟（Monte Carlo 思想）生成场景统计结果 |
| **模型** | ①司机收益最大化的决策模型；②乘车效率为目标的单目标优化（决策变量：上车点数量）；③长短途出租车空载率/收益差值最小的双目标优化（排队位置） |
| **创新点** | ①"蓄车池车辆数与等待收益负相关""21km 是决策转变点"等结论来自模拟分析；②对模拟截止时间 T₀ 做鲁棒性检验（40min 后趋于稳定值）；③对权重因子做灵敏度分析 |

### ⑥ 2022A 波浪能装置：物理定律驱动（微分方程建模）

| 环节 | 内容 |
|------|------|
| **线索** | 浮子受波浪激振力、PTO 阻尼力、弹簧力、静水回复力共同作用；垂荡与纵摇耦合 |
| **推断** | 这是一个动力学系统 → 用牛顿第二定律（/转动定律）建立运动方程 |
| **模型** | 垂荡：二元二阶常微分方程组；纵摇：四元二阶微分方程组；四阶龙格库塔离散求解；平均输出功率积分（梯形公式）→ 单目标优化（遗传算法搜索阻尼系数） |
| **创新点** | ①坐标系选取的灵活性（为建模服务）；②平行移轴定理 + 垂直轴定理计算组合体转动惯量（物理功底）；③"选取 100s 后稳定状态区间求平均功率"（处理振荡问题的工程智慧） |

### ⑦ 2023B 多波束测线布设：几何驱动

| 环节 | 内容 |
|------|------|
| **线索** | 多波束测深是"扇面"扫测，覆盖宽度与开角、坡度、水深、测线方向角有确定的几何关系 |
| **推断** | 这是纯几何问题 → 建坐标系、用向量/三角/正弦定理推导 |
| **模型** | 问题一/二：几何推导（相似三角形、线面角、正弦定理）求覆盖宽度与重叠率；问题三：以测线总长度最短为目标的单目标优化（贪心算法 + 模拟退火互验）；问题四：单波束数据 → 最小二乘拟合坡面方程 + 分区域优化 |
| **创新点** | ①**先数学证明"平行等深线走向布设是最佳方案"**（用证明支撑方案选择，很高级）；②贪心与模拟退火两种算法结果互验；③灵敏度分析（开角、坡度） |

### ⑧ 2024A 板凳龙：几何 + 逼近驱动

| 环节 | 内容 |
|------|------|

| **模型** | 等距螺线方程 + 极坐标弧长公式 + 逐步逼近法（解极角）+ 向量分析/余弦定理求速度；碰撞检测模型（顶点落于他板范围判定） |
| **创新点** | ①用"逐步逼近"代替直接求解超越方程（数值智慧）；②问题五"速度等比缩放"的证明（一个把手速度变倍，其他同倍率变）——用数学证明回答问题 |

## 三、模型创新性的三个层次（从低到高）

从 8 篇论文看，国奖的"创新"通常不在发明新模型，而在：

1. **组合创新**（最常见）：经典模型的巧妙组合。如 2015A1 = 天文机理 + 最小二乘优化 + 图像处理；2019C = 决策模型 + 系统模拟 + 双目标优化。
2. **转化创新**：把看似无关的问题转化为熟悉的结构。如 2017A 把"标定问题"转化为"优化问题"（目标函数：误差平方和最小）；2016C 把"9 个离散模型"通过 log 变换提升为统一模型。
3. **处理细节创新**（最被低估）：约束条件的设置、区间的选取、阈值的确定、数据预处理方式。如 2018A 用"黄金分割法"而非穷举搜索厚度；2019C 对 T₀ 做鲁棒性分析；2023B 先证明最优方向再优化。

> 提醒：**"创新性"不是必须用没人用过的模型**。8 篇论文用的都是经典模型（多项式、PDE、优化、几何、模拟），创新体现在**如何组合、如何转化、如何处理细节**。

## 四、为什么国赛优秀论文几乎不用机器学习（重点解读）

从 2015 到 2024 的一等奖论文看，**机器学习（BP 神经网络、随机森林、XGBoost 等）几乎不出现在主模型中**。原因：

1. **可解释性差**：评阅人需要理解"为什么选这个模型"，黑箱模型无法展示内部逻辑，与"线索→模型"的评审逻辑冲突。
2. **数据量不足**：国赛题目数据通常只有几十到几千行，深度学习/复杂 ML 容易过拟合，且展示不出"建模功力"。
3. **可检验性弱**：优秀论文必须做误差分析、灵敏度分析、稳定性分析，ML 模型很难给出清晰的误差传递与灵敏度结论。
4. **评分导向**：评阅专家多为数学/工程背景，更欣赏机理模型、经典统计、优化算法的推演之美。
5. **可复现性**：ML 训练过程随机性强，难以让评阅人复现结果。

**替代路线（用经典方法达到 ML 效果）**：
- 需要"预测"→ 用曲线拟合、回归、差分方程、灰色模型（GM(1,1)）、时间序列 ARIMA；
- 需要"分类/识别"→ 用判别分析、聚类（K-means）、层次分析、贝叶斯分类；
- 需要"找规律"→ 用统计分析（相关分析、假设检验、主成分分析）、log 变换、无量纲化；
- 需要"评价"→ 用层次分析法（AHP）、熵权法、TOPSIS、灰色关联分析；
- 需要"优化"→ 用线性/非线性规划、动态规划、遗传算法、模拟退火、蚁群；
- 需要"机理"→ 用微分方程、差分方程、排队论、马尔可夫链、元胞自动机。

> 如果你必须提及 ML（比如题目明确要求数据挖掘），正确姿势是：**用经典方法做主线，ML 只做对照或辅助验证**，并解释"为什么经典方法更合适"。

## 五、"线索 → 模型"写作检查清单

每建一个模型，回答以下问题并在论文中写明：

- [ ] 我观察到的数据/物理/文献线索是什么？（一句话，最好配图）
- [ ] 这条线索指向什么结构（线性/二次/指数/守恒/几何/随机）？
- [ ] 我选的模型为什么恰好能刻画这个结构？
- [ ] 如果换一个模型（尤其 ML），为什么不如当前模型？（可简要说明）
- [ ] 模型中的每个假设是否都能从线索或文献找到支撑？

## 六、全量阅读补充：152 篇中"线索→模型"的高频模式库

基于全部 152 篇的阅读，国奖论文的"线索"其实可以归为 **6 类高频模式**，写作时直接对号入座：

| 线索类型 | 常见表述 | 指向的模型 | 案例 |
|---------|---------|-----------|------|
| ① 图像/曲线形态 | "画图发现曲线呈二次/指数/先快后慢趋势" | 多项式/指数拟合、分段拟合 | 2016C（025/026）、2021B（100） |
| ② 统计特征 | "计算皮尔逊系数发现强相关""数据呈泊松分布" | 回归、方差分析、随机规划 | 2021B（098）、2021C（103） |
| ③ 物理/化学定律 | "由朗伯贝尔定律""由牛顿第二定律""由能量守恒" | 微分方程、力学/传热模型 | 2017A（030）、2018A（049）、2022A（112） |
| ④ 几何/空间关系 | "由对称性""由三角几何关系""建坐标系" | 几何推导、坐标变换、向量分析 | 2023B（127）、2024A（136）、2023A（123） |
| ⑤ 数据分布/聚类特征 | "任务聚集于四城市""品种内销量强相关" | 聚类、GIS 分析、指标体系 | 2017B（036/038）、2023C（131） |
| ⑥ 工程/业务约束 | "促动器伸缩量有范围""黑车切换代价高" | 优化模型（约束条件明确化） | 2021A（095）、2018D（058） |

**全量统计支持的结论**：
1. **"先观察后建模"是绝对主流**——拟合（33 篇）、模拟（26 篇）、回归（23 篇）居前三，都要求先看数据再定结构；
2. **优化模型是国奖的核心载体**——单/多目标优化合计 29 篇，遗传/模拟退火/蚁群等启发式算法合计 20+ 篇，几乎所有题都能落到"目标函数+约束"框架；
3. **评价体系化是 C/D 题标配**——模糊 11、聚类 11、层次分析 7、熵权 5，多级指标体系+客观定权成为常态；
4. **检验三件套（检验/误差/对比）出现率超过 90%**——"检验 46、误差 41、对比 39"意味着几乎每篇论文都做了这三件事之一；
5. **ML 是边缘选项**——152 篇中 ML 主模型不足 5 篇，且集中在光谱识别（2021E）、空气质量校准（2019D）这类"信号处理+分类"场景，主线仍是经典方法。
