# 《差分方程及其应用》(周义仓、曹慧、肖燕妮 编著) 建模方法总结

> **书目定位**：差分方程是"ODE/PDE 的简化版建模方法"——当数据按天/月/年离散记录、或只需关注离散时刻状态时，用递推关系建模比连续微分方程更自然、更易计算、更易被实际部门接受。本书从建模案例→求解理论→稳定性/分支分析→生态传染病应用，是一条完整的"离散建模"主线。

---

## 一、为什么竞赛要用差分方程（本书前言观点）

1. 经济、生态、社会、公共卫生、日常生活的数据**都是按天、周、月、季度、年汇总**的，用差分方程描述是自然选择，可直接模拟并与实际数据对比。
2. 差分方程本质是**递推关系**，比微分方程更容易理解和实现（计算机迭代即可）。
3. 差分方程是**微分方程的离散化**，是 ODE 数值计算（Euler 法、RK 法）的理论基础。
4. 简单的差分方程就能产生**非常复杂的动力学性态**（周期、混沌），描述力强。
5. 与微分方程理论高度平行：解的理论、稳定性理论、比较定理等都可以"平移"过来。

## 三、核心建模思想与武器库

### 1. 从实际问题建立差分方程的基本套路
识别"**下一时刻状态 = 上一时刻状态的函数**"，写出递推式：
- **兔子增长 / Fibonacci**：$r_n = r_{n-1} + r_{n-2}$（年龄/结构递推）。
- **养老保险**：$S_{k+1} = S_k(1+r) + p$（积累递推：账户余额=上期余额+利息+缴费）。
- **蛛网模型（物价波动）**：$y_k = f(x_k)$（需求），$x_{k+1} = g(y_k)$（供给）→ 组合为 $x_{k+1} = -\alpha\beta x_k + \alpha\beta + b$。
  - **平衡点稳定条件 $|\alpha\beta| < 1$**；$=1$ 周期振荡；$>1$ 发散振荡。→ 政策含义：提高供给对价格的敏感度可平抑物价。
- **遗传模型**：基因型比例的状态转移矩阵迭代，极限为纯合 AA。
- **租车点车辆比例 / Markov 链**：$\alpha(t+1) = A\alpha(t)$，稳定分布由最大特征值 $\lambda_1=1$ 的特征向量给出。
- **多阶段种群模型**：$L(t+1)=bA(t),\ P(t+1)=(1-\mu_L)L(t),\ A(t+1)=(1-\mu_P)P(t)+(1-\mu_A)A(t)$ → 矩阵形式 $\alpha(t+1)=M\alpha(t)$；非线性修正用 $e^{-cA(t)}$ 表示"自相残杀概率"。

### 2. 求解方法（第2章）
- **特征根法**：$r_n = \lambda^n$ 代入常系数线性差分方程 → 特征方程 → 通解 = 特征根幂的组合（含重根 $n^k\lambda^n$）。
- **算子法**：差分算子 $\Delta$、位移算子 $E$，$\Delta = E - I$，用算子多项式求解（类比微分算子法）。
- **非齐次方程**：特解用待定系数法（类比常微分方程）。
- **线性差分方程组**：矩阵迭代 $\alpha(t) = M^t \alpha(0)$，用特征值/特征向量分解；Markov 链稳态、热传导方程离散化等应用。

### 3. 稳定性分析（第3章，判断长期行为）
- **平衡解（不动点）**：$\bar x = f(\bar x)$。
- **线性化方法**：$x_{n+1}=f(x_n)$ 在平衡点附近 $f'(\bar x)$ 决定稳定性——**$|f'(\bar x)|<1$ 稳定，$>1$ 不稳定**（类比 ODE 的线性化）。
- **比较原理 / 差分不等式**：用上下解估计解的范围。
- **Liapunov 直接方法**：构造 $V(x_n)$ 沿轨线递减 → 稳定/渐近稳定；**LaSalle 不变性原理**判断全局渐近稳定。
- **应用**：两阶段种群模型、时滞种群模型、两种群竞争模型的分析。

### 4. 分支与复杂动力学（第4章，进阶）
- **分支点**：参数变化使平衡解稳定性改变或分支出现。
- 类型：**鞍结点分支、跨临界分支、音叉分支（pitchfork）、反转分支（flip，倍周期）、Hopf 分支（不变闭曲线）**。
- **虫口方程 $x_{n+1}=bx_n(1-x_n)$**：随参数 $b$ 增大：稳定平衡 → 倍周期分叉 → 混沌（竞赛中的"周期倍增通向混沌"）。
- **帐篷映射**：简单分段线性映射产生混沌。
- 意义：模型参数范围决策（如捕捞强度、防疫力度）要避开分叉/混沌区域。

### 5. 应用模型（第5章，竞赛直接可用）
- **Leslie 人口/种群矩阵模型**：按年龄分组的投影矩阵 $L$，$x(t+1)=Lx(t)$；增长率由最大特征值决定（净繁殖率）；可加入非线性密度制约。
- **离散传染病模型**：SIS（无免疫）、SIR（康复免疫）、SEIR（潜伏期）的离散版——**直接可用于疫情赛题**；带感染阶段的 HIV/AIDS 模型、季节性结核模型、年龄结构模型。
- **Beverton-Holt 渔业资源模型**：$x_{n+1} = \frac{rx_n}{1+kx_n}$（离散 Logistic 的替代），分析可持续收获与脉冲收获策略。

## 四、建模启示总结

1. **先问数据是离散还是连续**：按时间点记录 → 差分方程；连续变化 → 微分方程；两者可以互化。
2. **差分方程是"简化版"建模利器**：机理复杂的连续过程，可先用离散递推做简化模型（照片标注的核心观点）。
3. **矩阵化**：多阶段/多状态系统写成 $x_{t+1}=Ax_t$，用特征值分析长期行为（增长/衰减/稳定比例）。
4. **稳定性判据**：一维映射看导数；多维看 Jacobian 特征值；大范围用 Liapunov 函数。
5. **警惕复杂动力学**：非线性离散模型可能出现周期、混沌，参数设计要避开。
6. **与计算机天然亲和**：递推可直接编程模拟，适合竞赛中"数值模拟+图形展示"。

## 五、与《常微分方程》《数学模型》的衔接

- 差分方程 = 微分方程的离散化：**Euler 折线法 $y_{n+1}=y_n+hf(x_n,y_n)$ 就是把 ODE 变成差分方程**（本书第1章也讲了近似计算与差分方程的关系）。
- 《0数学模型》第6章（差分方程与代数方程模型）的案例（贷款购房、蛛网、Leslie）与本书第1、5章对应，可交叉阅读。
- 照片标注重点：把本书当作"ODE/PDE 简化建模方法"来用——竞赛中建立离散版本模型往往比连续模型更易求解、更易解释。
