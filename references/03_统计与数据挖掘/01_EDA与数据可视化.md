# EDA 探索性数据分析与数据可视化

## EDA 三目的

1. 明悉数据含义、发现异常、便于清洗；
2. 描述个案和变量特征，为后续选方法提供依据；
3. 把业务问题转化为数据分析问题。

## EDA 分析清单（写"数据预处理"章节骨架）

1. **筛查**：缺失？异常？重复？样本均衡？需转换？需新增变量？
2. **特征描述**（按变量类型选工具）：
   - 连续变量 → 均值/中位数/四分位数/标准差 + 直方图/茎叶图/箱线图
   - 无序离散 → 频数/占比 + 频数表/条形图/饼图
   - 有序离散 → 频数/占比 + 频数表/条形图
3. **变量关系**：
   - 连续×连续 → 散点图/热图 + Pearson/Spearman/Kendall
   - 有序×有序 → 交叉列联表 + Spearman/Kendall
   - 无序×无序 → 交叉列联表 + φ/V/列联系数
   - 离散×连续 → 箱线图/小提琴图 + t 检验/方差分析
4. **正态性检验**：直方图、P-P 图、Q-Q 图（点近直线则正态）；Shapiro-Wilk（小样本）、Kolmogorov-Smirnov（大样本）。不正态 → Box-Cox 变换。

## 常用统计图速查

| 图 | 适用 |
|---|---|
| 条图/柱形图 | 分类数据频数分布 |
| 线图 | 连续变量随时间趋势 |
| 饼图 | 总体构成比例 |
| 箱线图 | 分布（5 特征值：min/QL/Me/QU/max） |
| 散点图 | 两变量关系与趋势 |
| 直方图 | 连续变量频数分布 |
| P-P/Q-Q 图 | 检验是否服从某理论分布 |

**直方图 vs 条形图（易画错）**：条形图用条长表示类别频数、宽度固定、条分开（分类数据）；直方图用**面积**表示频数、矩形连续排列（数值型数据）。

## 描述统计量

- **集中趋势**：均值（易受极端值）、中位数（稳健）、众数。
- **三者关系判偏态**：对称（均=中=众）；左偏（均<中<众）；右偏（众<中<均）。
- **离散**：极差、方差/标准差、标准误 S.E.=s/√n。
- **形状**：偏度 Skewness（0 对称，>0 右偏）；峰度 Kurtosis（0 正态）。
- **标准分数** z=(x-x̄)/s：判离群点（|z|>3）、标准化。

## CRISP-DM 建模六步流程（竞赛直接套用）

```
商业理解（读题+查文献）
→ 数据理解（描述统计+探索）
→ 数据准备（哑变量、衍生变量、清洗）
→ 建模（选方法、调参）
→ 评估（交叉验证）
→ 输出（论文呈现）
```

**变量衍生技巧**：哑变量（k 类→k-1 个 0/1）；BMI=体重/身高²；依据文献+背景构造衍生变量再筛选。
