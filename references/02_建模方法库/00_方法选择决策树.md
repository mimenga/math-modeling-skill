## 终极决策树

```
问题来了
 ├─ 要最优解？ → 决策变量+约束+目标 → 小规模:规划；大规模:启发式
 ├─ 要预测数值？ → 有时间顺序? → 是:ARIMA/Prophet/LSTM
 │                              └ 否:回归/随机森林/XGBoost
 ├─ 要排序评价？ → 主观权重:AHP；客观:熵权；综合:TOPSIS/模糊
 ├─ 要分类判定？ → 二分类:逻辑回归；表格:随机森林/XGBoost；异常:阈值法
 ├─ 要分组？ → K-means/层次（注意分组机制合理性）
 ├─ 随时间演化？ → 微分/差分方程
 ├─ 不确定/随机？ → 蒙特卡罗/随机规划
 └─ 网络/路径/地图？ → 图论
```

## 实战四原则

1. **优先最匹配的模型，而非最复杂**——"模型适用性"是评委最高频要求。
2. **多模型对比是硬加分项**——同一问用 2+ 方法求解并比较。
3. **每个模型准备"为什么不用别的"一句话**——如"用非线性回归而非线性，因残差显示非线性趋势"。
4. **现成代码库赛前备好**——插值、拟合、规划、图论、聚类、回归、随机森林、XGBoost、ARIMA、GM(1,1)、AHP、TOPSIS、熵权、遗传算法、模拟退火。

## 模型选择决策规则（数据量/可解释性）

1. 数据量 < 1000 且特征少 → 优先统计/传统模型，可解释性强。
2. 数据量 > 10000 → 可上树模型/梯度提升，性能优先。
3. 论文需要可解释性 → 线性模型、决策树、SHAP 解释。
4. 每个子问题必须有对比模型，禁止单一模型下结论。
5. 跨题型混合（数据+优化、评价+预测）很常见，分层处理：先预测/评价得到参数，再输入优化模型。
