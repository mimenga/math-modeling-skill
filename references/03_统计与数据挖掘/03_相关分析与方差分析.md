# 相关分析、偏相关与方差分析

## 三个相关系数

| 系数 | 适用 | 说明 |
|---|---|---|
| Pearson r | 连续变量线性相关 | 最常用；r∈[-1,1] |
| Spearman ρ | 定序/非正态非线性的秩相关 | 排序取秩再算 |
| Kendall τ | 定序（非参数） | 基于一致对/非一致对 |

**Pearson 显著性检验**：t = r·√(n-2)/√(1-r²)，df=n-2。

**关键判读**：若 |Spearman| 明显 > |Pearson| → 非线性关系 → 改用多项式/样条回归。

## 偏相关（多变量系统必备）

- **目的**：控制（剔除）其他变量影响，单独研究两个变量关系。
- 三要素：r₁₂·₃ = (r₁₂ - r₁₃r₂₃)/√[(1-r₁₃²)(1-r₂₃²)]。

**⚠️ 经典结论（解释混杂效应必用）**：身高-肺活量 r=0.588 显著，但控制体重后偏相关 r=0.093 不显著 → 是"身高→体重→肺活量"的间接效应。**两变量相关显著时，先问：是否有第三变量在背后起作用？**

## 方差分析 ANOVA（分类变量对连续变量的影响）

**基本思想**：组间方差 SSA（随机+系统误差）vs 组内方差 SSE（随机误差）；F=MSA/MSE 显著>1 → 因素有影响。

**使用前提**：正态性、方差齐性、独立性。

**单因素**：SST=SSA+SSE，F~F(k-1,n-k)。拒绝 H0 只表明"至少两组不等"，需**多重比较**（LSD/S-N-K/Tukey；方差不齐用 Dunnett's C）。

**双因素**：无交互 SST=SSR+SSC+SSE；有交互加 SSAB。交互作用图：两线**交叉**=有交互，**平行**=无交互。

**关系强度**：R²=SSA/SST。

## 一张图记住变量关系方法

```
连续×连续      → 相关分析（Pearson/Spearman）
定类×定类      → 列联分析（χ²）
二分类×连续    → t 检验
多分类×连续    → 方差分析 ANOVA
```
