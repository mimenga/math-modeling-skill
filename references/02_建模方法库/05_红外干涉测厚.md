# 红外干涉测厚（2025B 真题专题）

> 来源：2025 国赛 B 题真题模拟复盘（2026-09-05，桌面 b题模拟 文件夹）｜ 关键词：红外干涉、外延层厚度、Airy 多光束、Drude 模型、寻峰、非线性拟合

## 核心内容

**物理链条**：外延层（轻掺杂，折射率 n）+ 重掺杂衬底 → 红外反射谱上叠加干涉条纹。

1. **两光束模型（问题1）**：光程差 Δ=2d√(n²−sin²θ₀)，R(ν)=R₀(ν)+C·cos(4πSdν+φ₀)，S=√(n²−sin²θ₀)。厚度反演三等价形式：
   - 级差法 d=1/(2Δν̄·S)；阶数线法（极值半阶数 m/2 对 ν 稳健回归，斜率=2Sd）；FFT 法 d=f*/(2S)。
   - 色散判据：条纹周期随 ν 漂移 ⟹ 常数 n 有系统偏差，需 n(ν)=A+Bν² 修正。
2. **算法（问题2）**：频带选择（避开剩余射线带/等离子体区，SiC 取 1800–4000 cm⁻¹）→ ALS 硬基线（λ=1e8）→ FFT 带通 [0.6,1.8]×f* 增强 → 峰谷对称检测+抛物线细化 → 三法初估 → 多起点 LSF 精修 → 块 Bootstrap CI。**关键教训**：条纹幅度随 ν 衰减时全局突出度阈值会漏峰/错峰，导致阶数线序号错乱、斜率虚高 40%；须带通增强+局部阈值+迭代剔点。
3. **多光束（问题3）**：Airy 公式 ρ=(r₀₁+r₁₂e^{2iβ})/(1+r₀₁r₁₂e^{2iβ})。显著条件：|r₀₁r₁₂|² 不可忽略 + 层内透明（8πκνd≪1）+ 相干性。**判定代理量**：|r₀₁r₁₂|² 随 ν 分布 + 条纹谐波比 H2/H1 + 两光束波形是否违反能量守恒（>100%）。
   - Si 重掺杂衬底低波数 |r₀₁r₁₂|²≈0.02–0.14（显著，两光束估厚偏置可达 +13.8%，ΔBIC>10⁴）；SiC ≈10⁻⁶（纯多光束偏置 +0.31%，可忽略）。
   - **衬底相位陷阱**：|r₁₂| 小时多光束无关紧要，但 arg r₁₂(ν)（Drude）随 ν 漂移仍会搬动条纹相位——SiC 上表现为"背景抬升+周期缓变"，常数 n 两光束偏置 ~3%。修法：Airy + 色散 n(ν)=A+Bν²（约束 B≥0）+ Drude 衬底双角联合拟合，残差 RMS 从 0.58%→0.15%。
   - **偏置隔离实验（论文亮点）**：用拟合好的 Airy 模型生成合成谱→跑两光束算法→差值即纯效应偏置，把"多光束影响"从"色散/n 定标"中分离。
4. **参考答案量级**：SiC 外延 ≈7.6–7.7 μm，Si 外延 ≈3.4 μm；灵敏度：d∝1/n（n±1%→d∓1% 主导），频带/基线/角度均 <1.2%。

## 适用场景
透明薄膜红外/光学干涉测厚类题（SOI 埋氧、GaN 外延、介质膜）；凡"慢变背景+周期条纹"谱信号皆可套用该管线。

## 注意事项
- 附件低波数强色散区（剩余射线带、等离子体边）绝不能直接用于测厚。
- 折射率 n 是厚度的"定标"，d–n 存在固有简并：双角联合只提供冗余校验（S 随角度变化 <1%），不能分离 n 与 d；论文应把 n 不确定度作为主导系统误差讨论。
