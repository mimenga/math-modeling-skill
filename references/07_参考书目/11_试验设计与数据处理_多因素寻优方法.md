# 《试验设计与数据处理》(李云雁、胡传荣 编著，第4版) 建模方法总结

> **书目定位**：化工/食品/制药/生物/材料等专业的试验优化教材。核心思想：**用最少的试验次数获取最多的信息**——先科学设计试验方案（正交设计、均匀设计、优选法），再对试验数据做误差分析、方差分析、回归分析，最后找到最优工艺条件/配方/参数组合。对数学建模的价值：**凡"多个因素、多个水平，要求最优组合"的赛题（工艺参数优化、配方设计、条件寻优），本书是标准方法论**。未被照片划定，但数据处理方法与统计衔接紧密。

## 二、核心方法武器库

### 1. 误差分析（第1章，数据质量的"体检"）
- **误差分类**：随机误差（偶然因素，服从正态、可平均抵消、增加次数可减小）；系统误差（恒定/规律性，多次平均无效，须校正）；过失误差（粗心造成，应避免）。
- **精密度**（随机误差大小，重复性）vs **正确度**（系统误差大小）vs **准确度**（综合）。
- **平均值的选择**：算术（正态等精度）；加权（精度不同按权）；几何（取对数对称）；调和（倒数场合）；对数（传热/传质）。
- **异常值检验**：格拉布斯（Grubbs）检验、狄克逊（Dixon）检验等——**数据处理时剔除异常值需有统计依据，不能凭感觉**。
- **误差传递**：间接测量量的误差由各直接量的误差按偏导传播——建模中"由多变量函数算结果时，结果误差如何受输入误差影响"的量化工具（与灵敏度分析思想一致）。
- 建模启示：赛题数据处理第一步——检查数据可靠性，识别并合理处理异常值。

### 2. 方差分析（第3章）
- **单因素方差分析**：一个因素多个水平，检验水平间均值差异显著性（F 检验）。
- **双因素方差分析**：两个因素 + **交互作用**（无重复/重复试验两种情况）。
- 前提：正态性、方差齐性；事后多重比较。
- 建模启示：判断"哪个因素显著影响结果"——试验/调查数据的分组比较标准方法。

### 3. 回归分析（第4章）
- 一元/多元线性回归：建立因素与结果的关系式，显著性检验，因素主次判断（标准回归系数），**最优方案预测**。
- 非线性回归：线性化（取对数/倒数）或多项式回归（一元二次/多元二次）。
- Excel"规划求解"也可做回归（最小二乘为目标）。
- 建模启示：试验数据→回归模型→预测+优化（找使结果最优的因素组合）。

### 4. 优选法（第5章，单因素快速寻优）
- **黄金分割法（0.618法）**：单峰函数在区间内每次缩小区间 0.382，n次试验后区间缩为 0.618^n——最省试验次数。
- 分数法（Fibonacci 分数逼近）、对分法（单调性）、抛物线法（二次拟合逼近）、分批试验法、**爬山法（逐步提高）**（多因素逐步试探）。
- 双因素：对开法、旋升法、平行线法。
- 建模启示：只有一个/两个可控因素、目标是单峰时，用优选法少做试验找最优。

### 5. 正交试验设计（第6章，★多因素多水平寻优核心）
- **正交表**：如 $L_9(3^4)$——用部分"均匀分散、整齐可比"的试验点代表全部组合。
- **优点**：试验次数少、代表性强、可分析因素主次与最优水平组合、可考察交互作用。
- **直观分析法（极差分析）**：计算各因素各水平的平均结果 → **极差 R 判断因素主次** → 选各因素最优水平组成最优方案。
- **方差分析法**：把总离差分解为各因素与误差贡献 → F 检验因素显著性。
- **多指标、交互作用、混合水平**的处理。
- 建模启示：赛题给"几个因素几个水平，找最优参数"→ 正交表设计试验/仿真次数，极差分析找主次与最优组合——**论文中"多因素寻优"的规范表达**。

### 6. 均匀设计（第7章）
- 让试验点在试验范围内"均匀散布"（数论方法，王元、方开泰 1978），试验次数可以很少（≈因素水平数）。
- 适用于因素水平多、试验昂贵、正交表放不下时；结合回归分析建模。
- 建模启示：仿真代价高（如大规模模拟）时，用均匀设计选取少量参数组合点。

### 7. 回归正交试验设计（第8章）
- **一次回归正交设计**：两水平正交表 + 回归，建立线性模型。
- **二次回归正交组合设计/旋转组合设计**：在中心点+轴向点补充试验，建立二次曲面模型（含交互项、平方项），精度高、可旋转性。
- 建模启示：既想找最优又想建立"因素-响应"曲面模型 → 响应面方法（RSM）的经典实现。

### 8. 配方试验设计（第9章）
- **约束条件**：各成分比例和为 1（$x_1+\dots+x_p=1$）。
- **单纯形格子点设计、单纯形重心设计**：在单纯形内选代表点试验，建立配方-性能模型。
- 建模启示：混合比例问题（混凝土配比、饲料配方、合金成分）→ 配方设计。

## 三、建模启示总结

1. **多因素寻优三件套**：正交设计（或均匀设计）安排试验/仿真 → 极差/方差分析定因素主次 → 回归/响应面建立关系模型并预测最优。
2. **误差分析是数据可信度保障**：区分随机/系统误差、统计检验异常值，论文"数据预处理"部分体现严谨。
3. **优选法适合连续单因素**：0.618 法、爬山法是"少做试验找最优"的朴素利器。
4. **试验设计与数据处理相配合**：设计决定了数据的"信息含量"，分析决定了从中提取什么规律——两者一体。
5. **用软件实现**：Excel（数据分析工具库、规划求解）、SPSS、Origin——竞赛中用 Python/R 等价实现即可。

## 四、与相关书目衔接

- 《6应用统计学》：方差分析、回归分析的方法原理；本书是"试验数据版"应用。
- 《5数值计算方法2006》：最小二乘拟合是回归的算法基础；插值用于试验点补全。
- 《9智能优化算法》：大规模多因素寻优（连续/离散）可用 GA/PSO/SA 替代或补充正交设计。
- 《0数学模型》：多因素优化赛题（配方、工艺、调度参数）的建模后求解可用本书方法论。
- 竞赛套用路径：**多因素多水平寻优 → 正交/均匀设计 → 方差/极差分析 → 回归/响应面 → 最优方案+验证试验**。
