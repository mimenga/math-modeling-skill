# 《机器学习方法》(李航 著) 建模方法总结

> **书目定位**：国内最权威的机器学习教材（由《统计学习方法》升级，2022年新版），分**监督学习、无监督学习、深度学习**三篇 29 章。每章严格按"**模型-策略-算法**"三要素组织，数学推导严谨。对数学建模的价值：**当赛题需要"从数据中学习规律、做分类/回归/预测/聚类"时，本书提供系统化的现代方法库**——传统机器学习擅长小数据、相对简单问题，深度学习擅长大数据、复杂问题。未被照片划定，但近年数据类赛题（分类、预测、图像识别、时序）越来越多，本书是数据驱动建模的"高阶武器库"。

## 二、核心思想：机器学习三要素（第1章）

1. **模型**：假设空间——从输入到输出的映射函数集合（决策函数 $y=f(x)$ 或条件概率 $P(Y|X)$）。
2. **策略**：评价准则——损失函数（0-1、平方、绝对、对数似然损失）+ **经验风险最小化 / 结构化风险最小化**（加正则项防过拟合）。
3. **算法**：求解最优化问题的具体方法（梯度下降、牛顿法、SMO、EM 等）。

**关键概念**：
- **训练误差 vs 测试误差**：测试误差（泛化误差）小才是好模型。
- **过拟合与正则化**：模型复杂度过高→过拟合；用正则化项（L1/L2）、交叉验证控制。
- **交叉验证**：简单交叉、k折交叉验证、留一法——数据少时的模型选择标准做法。
- **生成模型 vs 判别模型**：朴素贝叶斯、HMM 是生成模型（学习联合分布）；感知机、SVM、CRF、逻辑回归是判别模型（直接学习条件概率/决策函数）。
- **三类任务**：回归（输入输出连续）、分类（输出有限离散）、标注（输入输出为序列）。

> 建模启示：竞赛中"有标签数据做预测/分类" → 监督学习；"无标签数据分群/降维" → 无监督学习；**先用传统方法（逻辑回归、决策树、SVM、kNN）快速建立基线，再考虑深度学习**。

## 三、监督学习武器库（竞赛高频）

| 方法 | 适用问题 | 特点与用法 |
|---|---|---|
| **感知机** | 线性可分二分类 | 最简分类器；误分类驱动迭代；可作基线 |
| **k近邻（kNN）** | 分类/回归 | 无需训练、基于距离投票；数据标准化重要；k 和距离度量需调 |
| **朴素贝叶斯** | 文本分类、离散特征分类 | 假设特征条件独立；简单快；需平滑（Laplace） |
| **决策树（ID3/C4.5/CART）** | 分类/回归、可解释 | 信息增益/基尼指数选特征；剪枝防过拟合；结果可解释性好（论文友好） |
| **逻辑斯谛回归** | 二分类/多分类概率预测 | 输出概率（可解释、可校准）；L2 正则；**分类问题的默认基线** |
| **SVM** | 小样本高维分类 | 核技巧（线性/多项式/RBF）处理非线性；对偶+SMO；适合特征维数高样本少 |
| **AdaBoost/提升树/GBDT** | 分类/回归 | 弱分类器加权集成；**集成学习效果好**；竞赛常用（XGBoost/LightGBM 是其工程化） |
| **EM算法** | 含隐变量模型 | 高斯混合模型 GMM 聚类、参数估计 |
| **HMM** | 时序标注（语音、基因、文本） | 三大问题：概率计算（前后向）、解码（Viterbi）、学习（Baum-Welch） |
| **CRF** | 序列标注（NER、分词） | 判别式，特征灵活；与 HMM 互补 |

## 四、无监督学习武器库（竞赛高频）

- **聚类**：k均值（k-means，指定k、迭代中心）、层次聚类（树状图、不用指定k）、密度聚类（DBSCAN，任意形状）——**客户分群、区域分类、图像分割**。
- **主成分分析 PCA**：降维去相关、可视化、消除共线性（与《6应用统计学》第9章一致，本书给算法细节：特征值分解/SVD）。
- **奇异值分解 SVD**：矩阵低秩近似（图像压缩、协同过滤推荐的基础）。
- **PageRank**：有向图节点重要性——**排名问题**（网页、学术影响力、竞赛排名）的思想来源，与《0数学模型》第7章特征向量排名呼应。
- **MCMC（Metropolis-Hastings、吉布斯抽样）**：复杂分布抽样——贝叶斯推断、随机模拟的现代工具（与《4随机规划》随机模拟衔接）。
- **LDA/话题模型**：文本主题挖掘。

## 五、深度学习篇（简介）

- **前馈神经网络 + BP**：万能逼近；梯度下降/动量/Adam；正则化（dropout、早停）。
- **CNN**：卷积+池化提取空间特征——图像分类、目标检测（ResNet 残差网络加深不退化）。
- **RNN/LSTM/GRU**：序列数据（时间序列、文本）建模——时序预测赛题可用。
- **Seq2Seq + Attention + Transformer**：机器翻译、文本生成；预训练模型 GPT/BERT 是现代 NLP 基石。
- **GAN**：生成数据（图像生成、数据增强）。
- 使用前提：**大数据量 + 算力**；小数据赛题优先用传统方法。

## 六、建模启示总结

1. **分类/预测赛题的通用流程**：数据清洗→特征工程→划分训练/验证/测试→选模型（逻辑回归/决策树/SVM/集成）→交叉验证调参→评估（准确率、F1、AUC）→结果解释。
2. **可解释性优先**：数学建模竞赛论文要"讲道理"——决策树、逻辑回归比黑箱神经网络更受欢迎；深度学习用于"效果优先"的预测任务。
3. **集成学习是效果保障**：Boosting（AdaBoost、GBDT、XGBoost）、Bagging（随机森林）往往显著优于单个模型。
4. **无监督补充**：数据没标签先聚类（k均值/层次/DBSCAN）看结构；高维先 PCA 降维。
5. **避免过拟合**：正则化、交叉验证、早停——论文中要展示泛化评估（训练/测试误差曲线）。
6. **模型选择看数据规模**：小数据→SVM/逻辑回归/朴素贝叶斯；中数据→决策树/集成；大数据复杂问题→深度学习。
7. **与统计方法的衔接**：逻辑回归=广义线性模型；朴素贝叶斯=贝叶斯定理；PCA=线性代数——机器学习是统计学的现代延伸，可互相印证。

## 七、与相关书目衔接

- 《6应用统计学》：回归、聚类、判别、主成分的传统统计版；本书是机器学习版（算法+推导更系统）。
- 《0数学模型》第9章（统计模型：Logistic、判别、综合评价）：案例版；本书给理论。
- 《09智能优化算法》：神经网络（BP）的工程实现（MATLAB）；本书给数学推导。
- 《4随机规划与模糊规划》：随机模拟/Monte Carlo 与本书 MCMC 衔接。
- 《1差分方程》《2常微分方程》：HMM、动力系统与差分/微分方程的交叉（状态转移）。
- 竞赛套用路径：**有标签数据→监督学习（逻辑回归/决策树/集成）分类预测；无标签→聚类/PCA；序列→HMM/RNN；大数据复杂→深度学习**。
