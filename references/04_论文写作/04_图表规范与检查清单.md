# 图表规范与检验灵敏度

## 图表规范（评委第一眼好感度）

- 每图每表必编号（图 1、表 2）+ 标题（**图题在下方，表题在上方**）
- **图内禁止再嵌图号**（如 matplotlib `title` 写"图 3 销量分布"）：编号与图题由正文图题文字统一承担，图内标题只写内容描述或留空——双编号是评审一眼可见的格式硬伤
- 图上标注：坐标轴名称+单位、图例、数据标签
- 配色统一、低饱和专业色调（别用默认大红大绿）
- 能用图表达绝不用文字；图表要有解读文字（≥2 句）
- **三线表**统一格式
- **分辨率**：导出 ≥300 dpi 位图，能出矢量图（PDF/EPS/EMF）更好；截图一律禁止
- **数字写法规范**：图内文本、表格里禁止出现程序默认的 e 记法（`1.8e-05`）、伪下标（`10-18`、`b1`、`m2`）——科学记数写 `1.8×10⁻⁵`，上下标用真上下标（`β₁`、`R²`、`10⁻¹⁸`）；量级极小/极大时优先换单位（μm、万元、10⁴ kg）避免一串零。正文与图表口径必须一致，定稿前用 `scripts/13_数字一致性校验.py` 过一遍

## 国一论文的加分细节（2023–2025 八篇获奖论文验证）

1. **图注携带关键情景参数**，让图表自解释：
   "图 16 生存曲线及 NIPT 最佳时点（男胎孕妇，达标率 α=0.7）""图 2 碰撞时刻 t=412.48 s 时板凳龙位置图"。
2. **统计表配显著性星号 + 注释行**：表内 \*\*/\*\*\* 标记，表底注"\*\* 在 0.01 级别（双尾），相关性显著"；相关表可再配一张"强度对照表"。
3. **结果表带误差/优度列**：RMSE、R²、MAPE、相对误差作为表格专列，不止写在文字里。
4. **大表抽代表对象**：223 节板凳取 9 个代表节、54 种作物取 20 个进正文，表注写"仅展示部分，完整数据见附录"；全量进支撑材料。
5. **算法题标配"迭代过程表 + 收敛图"**：迭代过程表（次数 | 当前取值 | 目标值 | 收敛方向）+ 迭代次数-目标值收敛曲线——二分/启发式搜索务必留这两样证据。
6. **蒙特卡洛图用"均值线 + 95%CI 阴影带"**，一张图同时呈现趋势与不确定性。
7. 图表横向对比解读句式："对比图 16、17、18 可以发现……，可能是因为……"（结论 + 机理解释双落点）。

## 建议图型

| 场景 | 图型 |
|---|---|
| 趋势 | 折线图 |
| 分布 | 直方图/箱线图 |
| 关系 | 散点图+拟合线 |
| 相关性 | 热力图 |
| 对比 | 柱状图 |
| 方案 | 流程图 |
| 生存/达标类数据题 | 生存曲线 + 最佳时点竖虚线 |
| 分类模型 | ROC/PR 曲线 + 混淆矩阵 |
| 迭代/搜索类算法 | 收敛曲线 + 迭代过程表 |
| 不确定性量化 | 均值线 + 95%CI 阴影带 |

**密度参考**：平均每页 ≥0.5 个图表；正文先"如图 X 所示"再出现图。
