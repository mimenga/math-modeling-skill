# 报童模型与随机库存优化（补货/进货/订货类问题的主武器）

> **业务关键词别名**：补货量、进货量、订货量、订购量、库存、缺货损失、过期损耗/废弃、保质期短、当天卖不完、进货太多/太少、风险与收益权衡。
> 检索到本卡 = 需求不确定下的**单期**库存决策。典型真题：2023C 蔬菜补货（当年多支国一队伍的核心打法：去季节化 → Lasso/Prophet 预测 → 报童模型定补货量）。

## 一、什么时候用（识别信号）

- 商品保质期短 / 单销售期：卖不完报废（过剩损失），备太少缺货（缺货损失）；
- 决策量是"进多少 / 订多少"，而需求只能预测（有不确定性）；
- 目标是期望利润（或期望损失）最大化。

## 二、核心公式（临界分位数 / 边际均衡）

设 `Cu` = 单位缺货损失（≈售价−成本，少赚的边际收益），`Co` = 单位过剩损失（≈成本−残值，多进的边际损失）：

**Q\* = F⁻¹( Cu / (Cu + Co) )**

- 需求 ~ N(μ, σ²) 时：Q\* = μ + σ·z(临界比)，z 为标准正态分位数；
- **经验分位数版（推荐，数据驱动）**：直接取需求样本（历史值或 Q2 预测值+残差扰动）的经验分位数 `Q* = quantile(样本, 临界比)`——评委问"凭什么假设正态"时无懈可击；
- 直觉：临界比 = "多进一件能卖出的概率阈值"；越怕缺货（Cu 越大），Q\* 越高，反之越保守。

## 三、三步论文写法

1. **假设**：需求 X~N(μ̂, σ̂²)——μ̂、σ̂ 来自预测模型（点预测 + 残差标准差），配正态性检验（JB/直方图/Q-Q）再写明；
2. **模型**：E[π(Q)] = Cu·E[min(X,Q)] − Co·E[(Q−X)⁺]，令 dE/dQ=0 得临界分位数公式（推导两行即可）；
3. **求解**：各品类（单品）Q\* 三线表（单位 kg）+ "临界比↔Q\*"灵敏度小图，呼应第 7 条硬约束四件套。

## 四、升级路径（国二 → 国一）

- 多品类预算/容量/品类占比约束 → 各品类报童分位数作系数，进 MILP 联合求解（配合 `01_优化类问题.md`）；
- 服务水平/置信度约束 → 机会约束规划（见 `07_参考书目/06_随机规划与模糊规划_不确定决策建模.md`）；
- 多周期滚动补货 → (s,S) 策略 / 动态规划（存储论扩展见 `07_参考书目/04_运筹学_优化决策工具箱.md`）。
