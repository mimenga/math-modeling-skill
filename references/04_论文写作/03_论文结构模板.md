# 论文结构模板（国奖标准骨架）

## 十二个模块

```
摘要（一页浓缩全文，逐问给方法与数字结果）
1 问题重述（背景 + 相关信息 + 待解决问题清单）
2 问题分析（★核心★ 逐问：这是什么类型问题 → 难点 → 拟用什么思路）
3 模型假设（每条带理由，很多引文献支撑）
4 符号说明（三线表，统一格式）
5 数据处理（★易忽视★ 先讲"从数据里看到了什么"）
6 模型建立与求解（逐问：准备→建模→算法→求解→检验）
7 模型检验（误差分析、与已知结果对比）
8 灵敏度/稳定性分析
9 模型评价（优点/缺点/改进/推广）
10 AI 工具使用声明（★硬约束：必须在参考文献之前★，二选一：未使用/使用+简要用途）
11 参考文献（规范引用，正文标注）
12 附录（程序、大表、推导）
```

## 每问内部结构

```
先分析 → 再建模 → 再求解 → 再检验
```

数据题/统计题推荐四段式：`X.1 数据预处理 → X.2 模型构建 → X.3 模型求解 → X.4 模型结果与误差分析`。

## 两种合法变体（国一论文实证，别纠结"标准答案"）

| 模块 | 变体 A：独立成章 | 变体 B：按问分布 | 怎么选 |
|---|---|---|---|
| 检验+灵敏度 | 单独第六/八章（几何/物理/优化题常用） | 每问末尾"模型结果与误差分析"小节（数据题各问方法不同时常用） | 全模型共用一套参数→独立成章；各问检验对象不同→按问分布 |
| 数据预处理 | 独立第五章：数据总览→特征分析→可视化（含"做什么+不做什么+为什么"与 1–2 条业务洞察） | 每问内部按需预处理 | 多问共用同一份清洗数据→独立成章；各问口径不同→按问分布 |

预处理章高分配写法：解释"不做某处理"的理由（如"保留基线是保证数据物理完整性的必要步骤"），并以业务洞察收尾（如"××有潜力成为新的增长极"），不止罗列清洗操作。

## 篇幅配比经验值（国一论文画像）

- **求解章是绝对主体**：占正文 60% 以上；
- 附录可占全文 1/3~2/3（代码按问题命名 + 中文注释），正文 20~30 页属正常区间；
- 问题分析章放**全文建模思路总流程图**（通常为图 1），评委定位思路最快的方式；
- 模型假设 3~5 条（2~6 条均见于国一），每条=假设+理由，最强写法是**定量解释**（"光锥半角展宽 4.65 mrad 在 20 m 内只导致 10 cm 内落点偏移……可忽略"）；
- 符号说明表约 20~25 个符号，三线表；
- 模型评价章四分：优点/缺点/改进/推广，缺点要具体化甚至量化（见 `08_高频句式与论证规范库.md` 第八节）。

## 各部分要点与扣分点

| 部分 | 要点 | 常见扣分 |
|---|---|---|
| 问题重述 | 每问一句话，别抄原文 | 复制粘贴 |
| 模型假设 | 3-5 条，每条=假设+理由 | 万能假设、无用假设 |
| 符号说明 | 三线表，全文统一 | 前后矛盾 |
| 模型建立 | 每问分写，公式编号，算法流程 | 只有代码没公式 |
| 模型求解 | 工具+算法步骤+中间结果 | 只给指标不给最优方案 |
| 结果分析 | 每结果配 2-3 句解读 | 只贴图表无解读 |
| 灵敏度 | 按 `07` 卡选范式重跑（±5%/分布/蒙特卡洛/对照/极值） | 缺失（国奖标志性步骤） |
| 模型评价 | 优点具体+缺点真诚 | 空夸、回避缺点 |

## 逻辑主线（一句话公式）

```
【数据线索/物理规律/文献结论】→【推断结构】→【选择模型】→【算法求解】→【检验误差】→【灵敏度】
```

**铁律**：模型出现前必须有"线索"；每个结论必须带数字。

## 创新点要明说

改进的约束、自创的评价指标、混合模型——都是加分项，别藏着。忌"万能模板套题"，模型与问题强绑定。
