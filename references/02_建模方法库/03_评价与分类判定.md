# 评价类问题（决策/排序）

| 方法 | 适用 | 特点 |
|---|---|---|
| 层次分析法 AHP | 定性+定量、少量方案 | 判断矩阵+一致性检验（CR<0.1） |
| 熵权法 | 客观权重 | 数据差异越大权重越高 |
| TOPSIS | 多指标排序 | 贴近正理想解 |
| 灰色关联分析 | 小样本、灰色系统 | 关联度排序 |
| 模糊综合评价 | 边界模糊 | 隶属度函数 |
| 主成分/因子分析 | 指标太多降维 | 提取主成分后加权 |
| CRITIC/组合赋权 | 更客观 | 客观权重进阶 |

## 写法要点

- **主观（AHP）+ 客观（熵权）组合赋权是加分项**。
- 给出权重敏感性分析（排序稳定性）。
- 权重来源要写清依据。

## 分类与异常判定

| 方法 | 适用 | 要点 |
|---|---|---|
| 逻辑回归 | 二分类概率 | 默认基线，可解释 |
| 判别分析 | 多分类 | Fisher/贝叶斯判别 |
| 决策树/随机森林 | 可解释分类 | 特征重要性 |
| SVM | 小样本高维 | 核技巧 |
| kNN | 简单分类 | 标准化重要 |
| 朴素贝叶斯 | 文本、离散特征 | 独立性假设 |
| XGBoost | 表格分类 | 竞赛首选；作主模型须配特征重要性/SHAP 解释并与逻辑回归等经典模型对比 |
| 孤立森林（Isolation Forest）/One-Class SVM | 异常检测 | **异常判定≠普通分类** |

## ⚠️ 异常判定 ≠ 普通分类（关键认知）

若题目是"异常判定"（如 NIPT 第 4 问），评委要的是：
1. 异常 vs 正常的**差异性分析**（哪些指标区分度大）
2. **明确的、可操作的阈值判定规则**
3. **优良性分析**：灵敏度/特异度/假阳性/假阴性 + 临床代价权衡

**重点在阈值设计和误判率权衡（假阳性 vs 假阴性），而非追求分类准确率**——这是 2025 年评阅要点明确指出的失分点。

## 分类题写法

混淆矩阵 + 准确率/召回率/F1 + ROC/AUC。多模型对比表 + 选优理由。
