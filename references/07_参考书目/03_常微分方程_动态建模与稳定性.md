# 《常微分方程》(王高雄、周之铭、朱思铭、王寿松 编，第四版) 建模方法总结

> **书目定位**：国内最经典的常微分方程教材。对数学建模而言，本书的价值集中在：**第1章的建模方法论**（怎样把实际问题写成 ODE）、**第6章的定性/稳定性分析**（不求解也能判断系统行为）、**附录A的模型库**（传染病、动力学、机器人等现成模型）。本书未被照片划定范围，但它是"动态系统建模"的理论基石。

## 二、第1章：建立常微分方程模型的方法（核心方法论）

本书总结的**四种建模方法**：

1. **从自然规律出发（机理分析）**：考虑主要因素、忽略次要因素，提炼状态变量，应用物理/化学/生物定律写出"自变量-未知函数-导数"的关系式。
   - 例：RL 电路 $L\frac{dI}{dt}+RI=E$（基尔霍夫定律）；数学摆 $\frac{d^2\varphi}{dt^2}+\frac{g}{l}\sin\varphi=0$。
2. **类比法**：利用"不同现象可以有相同数学模型"的事实，用已知系统模拟未知系统（电路模拟力学系统）。
3. **数据分析+逻辑推理**：从观测数据中发现规律建立模型（Malthus 人口模型、Logistic 模型）。
4. **反复试验/数值试验**：先建复杂模型，通过数值实验剔除次要变量（Lorenz 从 12 变量大气方程简化到 3 变量）。

> 重要发现（可转移性）：RL 电路方程、人口增长方程、冷却过程都写成 $\frac{dy}{dt}+ay=c$ 这一类型；RLC 电路与强迫振动摆都写成二阶线性方程——**学会识别"同一数学结构"**。

### 经典模型清单（第1章+附录A）
- **Malthus 模型**：$\frac{dN}{dt}=rN$，解 $N=N_0e^{r(t-t_0)}$（指数增长，短期有效）。
- **Logistic 模型**：$\frac{dN}{dt}=rN(1-\frac{N}{N_m})$，解为 S 形曲线——环境容纳量 $N_m$；预测极限人口。
- **Volterra 捕食-被捕食模型**：$\frac{dx}{dt}=x(a-by),\ \frac{dy}{dt}=y(-c+dx)$——食饵与捕食者此消彼长的周期震荡。
- **两种群竞争/共生模型**：$\frac{dx}{dt}=x(a+bx+cy),\ \frac{dy}{dt}=y(d+ex+fy)$，系数符号决定竞争/共生/捕食关系。
- **Lorenz 方程**：三变量混沌系统（蝴蝶效应、初值敏感性）。
- 附录A：传染病（SIR）、化学动力学、机器人、作战模型等。

## 三、第6章：非线性方程的定性分析（不求解也能建模分析）

### 1. Liapunov 稳定性与 V 函数（第二方法）
- **按线性近似决定稳定性**：在平衡点处线性化，Jacobian 矩阵特征值实部全为负 → 渐近稳定（类比差分方程 $|f'|<1$ 判据）。
- **V 函数法**：构造正定函数 $V(x)$，若沿轨线 $\frac{dV}{dt}\le0$ → 稳定；$<0$ → 渐近稳定。**不求解即可判断全局稳定性**，竞赛中分析模型长期行为的神器。
- 例：分析传染病模型平衡点的全局稳定性。

### 2. 定性理论：奇点、极限环、相平面
- **相平面分析**：平面自治系统 $\dot x=f(x,y),\dot y=g(x,y)$ 的轨线在相平面上的形态：
  - 奇点类型：结点、鞍点、焦点、中心（由 Jacobian 特征值决定）。
  - **极限环**：孤立的闭轨——自激振荡（如 Lotka-Volterra 周期解、心脏搏动模型）。
  - 等倾斜线方法：$f=0$（垂直等倾斜线）、$g=0$（水平等倾斜线）划分区域判断轨线走向。
- 建模意义：**系统长期行为（趋向平衡、周期振荡、发散）可完全由定性分析给出**，无需解析解。

### 3. 混沌与复杂现象
- **虫口模型（Logistic 映射）** $x_{n+1}=rx_n(1-x_n)$：倍周期分叉→混沌。
- **李-约克（Li-Yorke）混沌定理**："周期3意味着混沌"。
- **孤立子、Hamilton 系统**：可积系统的守恒量（能量）分析。
- 意义：非线性系统可能不可预测，建模时要识别参数区域。

## 四、求解工具箱（第2-5章）

| 方程类型 | 方法 |
|---|---|
| 变量分离 $y'=f(x)g(y)$ | 分离变量+积分 |
| 齐次 $y'=g(y/x)$ | 令 $u=y/x$ 化为分离变量 |
| 一阶线性 $y'+P(x)y=Q(x)$ | **常数变易法** / 积分因子 |
| 恰当方程 $Mdx+Ndy=0$ | 求势函数；非恰当用积分因子 |
| 高阶常系数线性 | 特征方程法；非齐次用待定系数法 |
| 微分方程组 | 化为矩阵指数 $e^{At}$；**拉普拉斯变换** |
| 数值解 | Euler 法、龙格-库塔法（附录B、第3章） |

- **拉普拉斯变换**：把微积分运算变为代数运算，适合带初值条件的线性系统（电路、振动、控制系统）。
- **n阶方程 → 一阶方程组**：令 $y_1=y, y_2=y', \dots$，所有高阶系统都可化成标准一阶系统形式，便于数值求解与定性分析。
- **边值问题**：Green 函数、本征值问题（与《3数学物理方程》衔接）。

## 五、建模启示总结

1. **动态过程先写"变化率=输入-输出"守恒式**：$\frac{d}{dt}$(总量) = 进入 - 离开 ± 产生 - 消耗。
2. **模型要随数据修正**：Malthus 不行就上 Logistic，Logistic 不行就上带时滞/年龄结构的模型——渐进式建模。
3. **不会解就定性**：平衡点+线性化+Liapunov 函数，三步分析长期行为，竞赛论文中非常出彩。
4. **相图/轨线图形是表达利器**：竞赛论文用相平面图展示系统行为比写公式更直观。
5. **识别可转移结构**：一阶线性、二阶线性、Lotka-Volterra 型、SIR 型——见到新问题先匹配已知结构。
6. **高阶系统化为方程组**：统一处理、便于数值计算。
7. **注意混沌边界**：非线性参数过大可能进入混沌，模型适用性有范围。
