# 数模合作专家 · 知识库总览

> 定位：一套**可直接用于全国大学生数学建模竞赛（国赛/高教社杯）**的数模协作 skill + 结构化知识库。
> 来源：个人备赛资料整理 + 数模协作方法论沉淀 + 12 本教材精读合并。

## 一、如何安装使用

本文件夹是一个完整的 AI 协作 skill，适配支持 skills 机制的 AI 编程工具（ZCode / WorkBuddy 等）。使用方法：

1. 把仓库内容放入**用户级 skills 目录**下的 `math-modeling-competition` 文件夹（克隆后文件夹名是仓库名，重命名或复制为该名称即可），使 `SKILL.md` 位于：
   ```
   <用户级 skills 目录>/math-modeling-competition/SKILL.md
   ```
   例：ZCode 为 `~/.zcode/skills/math-modeling-competition/SKILL.md`；WorkBuddy 为 `~/.workbuddy/skills/math-modeling-competition/SKILL.md`。
2. 在对话中直接说"帮我做数模 C 题"、"分析这个题目"、"用决策树选模型"等，即可触发本 skill。
3. 可随时把资料喂进 `references/` 对应目录扩充知识库，并更新 `references/INDEX.md`。

## 三、核心结论（背下来）

1. **摘要定档次、模型定上限、细节定生死** —— 摘要 20-25%、模型建立 30-35%，两者合计过半。
2. **模型适用性 > 模型复杂度** —— 基础模型 + 完整流程 + 灵敏度分析 > 高级模型 + 潦草流程。
3. **数据题不要迷信机器学习** —— 真实数据误差大、样本少时，统计模型（混合效应、生存分析、阈值判定）更受评委认可。
4. **每个结论必须带数字 + 图 + 显著性检验 + 灵敏度分析** —— 数据题论文的"四件套"。
5. **AI 是工具人不是建模师** —— 2026 新规要求核心建模由队员主导，AI 使用需声明并附详情。
