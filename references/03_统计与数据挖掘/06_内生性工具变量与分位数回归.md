# 内生性、工具变量（2SLS）与分位数回归（C 题定价/弹性类进阶）

> **业务关键词别名**：价格对销量的影响、定价策略效果、价格弹性、弹性估计、促销效果、供需互相影响、因果效应、反事实。
> 定位：基础回归（`04_回归分析.md`）之上的"国二 → 国一"进阶层。2023C 类定价题的国一队伍普遍在此分档。

## 一、为什么"价格→销量"回归天生有内生性

- **联立性**：价格与销量由市场同时决定（进货成本高→定价高→销量低；销量又反过来影响定价），OLS 把双向效应混在一起，估出的"弹性"有偏；
- **遗漏变量**：促销、节假日、天气同时影响价与量，进入扰动项后与价格相关；
- 评委视角：**承认内生性并处理 = 因果思维显性化**，是"深层信息挖掘"档的标志（对标 [132] 价格弹性论文）；只讨论不处理也可，但处理了是硬加分。

## 二、工具变量 2SLS（首选解法，C 题里工具变量就用批发价/进货成本）

好工具变量的两个条件（论文里必须各写一句）：

1. **相关性**：批发成本显然影响定价（成本加成）——用第一阶段 F>10（单工具变量即 t²>10）验证；
2. **外生性**：成本不直接影响消费者当日购买意愿，只通过售价传导。

两阶段流程：

- 第一阶段：`售价 = a₀ + a₁·批发成本 + 控制项 + ε₁`（看 a₁ 的 t/F）；
- 第二阶段：`log(销量) = b₀ + b₁·售价拟合值 + 控制项 + ε₂`，**b₁ 即因果弹性的估计**。

论文写法：两阶段系数**对比表**（OLS vs 2SLS）——两者差异大，这本身就是一条发现（"OLS 低估了提价的销量损失"）；再讨论工具变量弱点（如成本同时影响非价格渠道）显严谨。

代码：`scripts/12_C题定价补货专题.py` 的 `iv2sls_elasticity()`（statsmodels 手写两阶段，无需额外依赖）。

## 三、分位数回归（异方差 / 尾部 / 稳健场景）

- **何时用**：残差喇叭形（异方差）、关心"高销量/低销量端"规律、需要稳健于异常值；
- **模型**：Q_y(τ|x) = x'β(τ)，τ=0.25/0.5/0.75 各估一套系数；
- **论文亮点句式**："价格弹性随分位数上升而绝对值增大——薄销单品对提价更敏感"，配三系数对比小表或系数随 τ 变化的扇形图；
- 代码：`scripts/12` 的 `quantile_elasticity()`（statsmodels QuantReg）。

## 四、答题选择器

| 你手上的问题 | 用什么 |
|---|---|
| 只要价格-销量关系用于定价寻优 | OLS / log-log 即可（模型评价里写明局限） |
| 结论要谈"效果/因果"或冲击国一 | + 2SLS（批发成本作工具变量） |
| 残差异方差 / 想挖尾部规律 | + 分位数回归 |
| 面板结构（多品类/多店 × 时间） | + 固定效应（品类/日期哑变量或 within 变换） |
