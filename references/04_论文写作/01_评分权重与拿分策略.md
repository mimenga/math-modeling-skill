# 评分权重与拿分策略

## 评分权重（历年流传的经验估计，组委会并不官方公布——引用时勿写"官方"）

| 板块 | 权重 | 核心要求 |
|---|---|---|
| **摘要** | 20-25% | 定档核心！含方法+数字，独立成篇 |
| **模型建立** | 30-35% | 假设合理、公式规范、逻辑闭环、适配题目 |
| **模型求解** | 15-20% | 算法可行、结果可复现、工具明确 |
| **结果分析与检验** | 15-20% | 解读结果 + 灵敏度 + 稳健性 |
| **排版规范+文笔** | 10-15% | 不加分但错必扣 |

**评委阅卷逻辑**：先看摘要定档 → 再看模型看功底 → 最后看细节定高低。

**拿分公式**：
- 保底获奖 = 规范摘要 + 合理假设 + 适配模型 + 完整求解 + 无低级错误
- 冲刺国奖 = 基础满分 + 模型微创新 + 灵敏度分析 + 多模型对比 + 深度结果解读

## 致命扣分项（千万别踩）

| 雷区 | 后果 |
|---|---|
| 摘要空话无数字 | 直接锁定低档 |
| 模型与题目脱节（万能模板） | 严重扣分 |
| 数据异常/缺失未处理 | 严谨性扣 2-5 分 |
| 变量前后定义不一致/公式错误 | 态度不严谨 |
| 图表无编号无标题 | 规范分扣光 |
| 只建模不求解/只分析不落地 | 内容空洞 |
| 参考文献虚构 | 学术不端 |
| 抄袭/整段复制 | 取消资格 |
| 缺少 AI 声明 | 2026 新规违规 |

## 评阅人 10 分钟内想看什么

1. **摘要**：逻辑通顺、数字详实 → 10 秒定印象
2. **问题分析**：思路清晰、敢于定性 → 确认建模思想
3. **模型**：有依据、有推导、可复现 → 验证功底
4. **图表**：规范、有解读 → 验证严谨与工作量
5. **检验**：误差、灵敏度 → 验证可信度
6. **评价**：真诚的优缺点 → 验证认知深度
