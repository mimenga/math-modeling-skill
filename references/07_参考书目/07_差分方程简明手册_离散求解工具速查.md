## 二、核心工具速查

### 1. 差分与差分方程基本概念
- **一阶差分**：$\Delta f(x) = f(x+1) - f(x)$（约定步长1，否则 $x=t\Delta x$ 代换）。
- **n阶差分**：$\Delta^n f(x) = \Delta(\Delta^{n-1}f(x))$，与"相继值"互化：$f(x+n)=\sum\binom{n}{i}\Delta^i f(x)$。
- **阶乘函数** $x^{(n)}=x(x-1)\cdots(x-n+1)$：差分学中的"幂函数"，$\Delta x^{(n)}=nx^{(n-1)}$——**求和/差分运算可像幂函数一样套公式**。
- **差分方程两种形式**：$\Phi(x, y_x, \Delta y_x,\dots)=0$ 或递推形式 $\Phi(x, y_x, y_{x+1}, \dots, y_{x+n})=0$（后者更常用）。
- **阶**：未知函数下标最大值与最小值之差。
- **通解/特解**：含n个任意常数为通解；由初值条件确定特解。

### 2. 函数求和（离散微积分）
- **不定和** $\Delta^{-1}g(x)$：满足 $\Delta F(x)=g(x)$ 的 $F(x)+C$（类比不定积分）。
- **Newton-Leibniz 公式（离散版）**：$\sum_{i=0}^{n-1} g(a+i) = F(a+n) - F(a)$（类比定积分基本定理）。
- **分部求和（Abel 公式）**：$\sum a_k\Delta b_k = a_nb_n - a_0b_0 - \sum b_{k+1}\Delta a_k$。
- 用途：**求显式递推和的封闭公式**——竞赛中由递推数据求总量/累计值。

### 3. 线性差分方程求解（重点）
- **解的结构**：非齐次通解 = 齐次通解 + 特解（与 ODE 完全平行）。
- **特征根法（常系数齐次）**：$y_k=\lambda^k$ 代入 → 特征方程 $a_0\lambda^n+a_1\lambda^{n-1}+\dots+a_n=0$：
  - 相异实根：$y_k=C_1\lambda_1^k+\dots+C_n\lambda_n^k$；
  - 共轭复根 $re^{\pm i\theta}$：$y_k=r^k(C_1\cos k\theta+C_2\sin k\theta)$（振荡项！）；
  - m重根：乘 $k^0,\dots,k^{m-1}$。
- **待定系数法（非齐次）**：右端 $r(k)$ 为多项式×$b^k$ 或 $b^k\sin/\cos$ → 设对应形式特解（特征根重合时乘 $k^m$）——**与 ODE 待定系数法完全一致**。
- **常数变易法**：齐次通解中常数"变易"为函数，解线性方程组求 $\Delta C_i(k)$。
- **算子法**：位移算子 $E$（$Ey_k=y_{k+1}$），$\Delta=E-1$；$f(E)b^k=b^kf(b)$；算子多项式因式分解降阶。
- **母函数法**：$G(t)=\sum y_k t^k$，把差分方程化为 $G(t)$ 的代数/微分方程 → 展开求系数。适合初值问题、变系数、非线性（如 Catalan 数 $y_n=\sum y_i y_{n-i}$）。

### 4. 变系数与非线性方程的转化技巧
- 变系数 → 常系数：变量代换 $y_k=f_k z_k$ 等。
- 降阶：已知一个非零解 → $y_k=f_k z_k$ 降阶；算子因式分解。
- **非线性 → 线性**：
  - 齐次型 $y_{k+1}y_k$：令 $z_k=1/y_k$；
  - 比内型 $y_{k+1}=ay_k^b$：取对数；
  - **Riccati 方程** $y_{k+1}y_k+p_ky_{k+1}+q_ky_k+r_k=0$：令 $y_k=z_k/z_{k+1}$ 化为二阶线性；
  - **Logistic 映射** $y_{k+1}=2y_k(1-y_k)$：令 $y_k=\frac12(1-z_k)$ 或 $y_k=\frac{1}{2}(1+e^{w_k})$ 可线性化。

### 5. 稳定性（第4部分）
- **平衡解**：不动点 $\bar y$（$f(\bar y)=\bar y$）。
- **自治线性方程组** $y_{k+1}=Ay_k$：**特征值模 $|\lambda_i|<1$ 全部成立 → 渐近稳定**；存在 $|\lambda_i|>1$ → 不稳定（离散系统的核心判据，对应连续系统的 Re$\lambda<0$）。
- **自治非线性方程组**：线性化（Jacobian 特征值判据）。
- **李雅普诺夫直接方法**：构造正定 $V(y_k)$ 沿轨线递减 → 稳定/渐近稳定（无需求解）。

## 三、建模启示总结

1. **这是一本"查表工具"**：竞赛求解差分方程时直接查特征根法/待定系数法/母函数法公式，节省时间。
2. **特征根法解读模型行为**：根>1 指数增长/发散、0<根<1 衰减、负根/复根 → 振荡——**从特征根直接读出解的形态**，写论文"模型分析"部分很有用。
3. **复根=振荡**：经济波动、种群周期、电路振荡的离散模型都会有共轭复特征根。
4. **母函数法是组合计数利器**：路径计数、括号组合、排队等计数问题（$y_n=\sum y_i y_{n-i}$ 型）用母函数求通项。
5. **非线性离散模型常可线性化**：竞赛中遇到 $y_{k+1}=ay_k(1-y_k)$、Riccati 型等，先试变量代换。
6. **稳定性三判据**：线性化特征值（局部）、V 函数（全局）、比较原理——与《1差分方程及其应用》第3章互补。
