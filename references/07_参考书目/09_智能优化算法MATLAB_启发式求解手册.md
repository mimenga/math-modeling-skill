# 《智能优化算法及其 MATLAB 实例》(包子阳、余继周、杨杉 编著，第2版) 建模方法总结

> **书目定位**：本书为《智能优化算法及其 MATLAB 实例》——8种经典启发式（智能）优化算法的实战手册：**遗传算法、差分进化算法、免疫算法、蚁群算法、粒子群算法、模拟退火算法、禁忌搜索算法、神经网络（BP）算法**。每章含：算法来源、原理、算法流程、**关键参数说明**、**MATLAB 仿真实例**。用途：当赛题是大空间、非线性、全局寻优、组合优化（NP 难题）时，传统精确算法失效，用本书算法求（近似）最优解。

---

## 一、为什么需要智能优化算法（第1章）

- **问题背景**：信号处理、图像处理、生产调度、任务分配、模式识别、自动控制、机械设计中的复杂组合优化问题。
- **传统方法困境**：牛顿法、单纯形法需遍历搜索空间，大规模问题产生"**组合爆炸**"，无法在短时间内求解。
- **共同特点**：受自然现象/生物群体行为启发；简单、通用、便于并行；**只需目标函数输出值，不需要梯度信息**。
- **应用流程（竞赛模板）**：问题 → 目标函数+约束（编码为适应度）→ 选智能算法 → 设参数 → MATLAB 迭代 → 最优解+收敛图。

## 二、8种算法速查表

| 算法 | 灵感来源 | 核心机制 | 适用问题类型 | 关键参数 |
|---|---|---|---|---|
| **遗传算法 GA** | 达尔文进化论+孟德尔遗传学 | 编码染色体→适应度评价→选择/交叉/变异迭代 | 函数优化、组合优化、调度、机器学习 | 种群规模、交叉概率、变异概率、迭代次数 |
| **差分进化 DE** | 群体合作竞争（Storn 1995） | 实数编码、差分变异（个体差向量）+交叉+一对一竞争选择 | 连续空间非线性优化（切比雪夫问题等） | 种群规模、缩放因子 F、交叉概率 CR |
| **免疫算法 IA** | 生物免疫系统（克隆选择学说） | 抗原识别、克隆选择、亲和度成熟、维持种群多样性 | 多峰函数优化（克服"早熟"）、模式识别 | 种群规模、克隆规模、变异概率 |
| **蚁群算法 ACO** | 蚂蚁觅食（信息素正反馈） | 信息素强度决定路径选择概率，正反馈强化短路径 | **离散组合优化**：TSP、路径规划、调度 | 信息素蒸发率 ρ、启发因子、蚂蚁数 |
| **粒子群 PSO** | 鸟群/鱼群觅食迁徙 | 粒子以速度运动，向个体最优 pbest 与全局最优 gbest 聚集 | 连续/离散非线性优化，多峰问题 | 惯性权重 ω、学习因子 c1/c2 |
| **模拟退火 SA** | 固体退火（Metropolis 1953，Kirkpatrick 1983） | 以概率接受劣解（Metropolis 准则），温度逐渐下降 | 组合优化、TSP、布局，克服局部极值 | 初始温度、降温速率、终止温度 |
| **禁忌搜索 TS** | 人类记忆过程（Glover 1986） | 邻域搜索+禁忌表（避免迁回）+藐视准则 | 组合优化、调度、图着色 | 禁忌长度、邻域结构、候选解数 |
| **神经网络 BP** | 生物神经元系统（McCulloch-Pitts 1943，Rumelhart 1985） | 多层前馈+误差反向传播调整权重 | 非线性映射、回归预测、模式识别、分类 | 网络结构、学习率、动量因子 |

## 三、核心算法详解（竞赛最常用）

### 1. 遗传算法 GA（第2章）
- **流程**：编码（二进制/实数）→ 初始化种群 → 适应度评价 → 选择（轮盘赌/锦标赛）→ 交叉 → 变异 → 生成新一代 → 迭代至收敛。
- **理论基础**：模式定理（短低阶高适应度模式指数增长）、积木块假设。
- **特点**：对参数编码操作、不需梯度、全局搜索、鲁棒性强；可能早熟收敛。
- **竞赛用法**：无约束/带约束优化、调度、特征选择、与模拟退火/局部搜索混合。

### 2. 粒子群算法 PSO（第6章，最简单易用）
- **速度-位置更新**：
  - $v_{i}^{t+1} = \omega v_i^t + c_1 r_1(pbest_i - x_i^t) + c_2 r_2(gbest - x_i^t)$
  - $x_i^{t+1} = x_i^t + v_i^{t+1}$
- **思想**：粒子向"自身历史最好"与"群体历史最好"聚集，惯性权重 $\omega$ 平衡探索/开发。
- **特点**：参数少、实现简单、收敛快；适合连续优化；离散问题用离散 PSO。

### 3. 模拟退火算法 SA（第7章）
- **Metropolis 准则**：新解更优则接受；更差则以概率 $P=\exp(-\Delta E/T)$ 接受（温度 $T$ 越高接受概率越大）。
- **降温过程**：$T_{k+1} = \alpha T_k$（$\alpha$ 通常 0.85~0.99），温度降到终止温度结束。
- **特点**：以概率跳出局部最优 → 理论上全局收敛；对初值不敏感。
- **竞赛用法**：TSP、布局、下料等组合优化；常与 GA/TS 结合做局部精化。

### 4. 蚁群算法 ACO（第5章，离散优化首选）
- **机制**：蚂蚁按"信息素强度+启发信息"概率选择路径；走完后按路径长度更新信息素（正反馈）；信息素按 $\rho$ 挥发。
- **特点**：分布式、无中心、正反馈自组织；适合 TSP、路径规划、物流配送。
- **变体**：精英蚂蚁系统、最大最小蚂蚁系统、基于排序的蚁群算法、自适应蚁群。

### 5. 差分进化 DE（第3章，连续优化强力工具）
- **变异**：$v_i = x_{r1} + F(x_{r2} - x_{r3})$（随机差向量缩放）；
- **交叉+选择**：与父代竞争，"一对一"生存；实数编码，无需编码解码。
- **特点**：结构简单、性能高效、记忆能力、全局收敛性强——**连续函数优化的默认选择**。

### 6. 神经网络 BP（第9章，数据驱动映射）
- **结构**：输入层-隐含层-输出层，激活函数（sigmoid/tanh/ReLU）。
- **学习**：误差反向传播（梯度下降）调整权重；需数据预处理（归一化）。
- **特点**：非线性映射、无需精确数学模型、擅长从数据学习；易过拟合（需正则/早停）。
- **竞赛用法**：回归预测、分类判别——与《7李航机器学习》互补（本书重实现，李书重理论）。

## 四、竞赛使用指南（本书的直接价值）

1. **何时用**：模型是 NP-hard/非线性多峰/搜索空间巨大/无法求导时——精确算法算不出，就用智能算法求"满意解"。
2. **如何用**：把赛题模型的目标函数+约束写成"适应度函数"（罚函数处理约束）→ 选算法 → 调关键参数 → MATLAB 运行 → 收敛曲线验证。
3. **参数调试是重点**（本书每章都有"关键参数说明"）：
   - GA：种群 20-100、交叉 0.6-0.9、变异 0.01-0.1；
   - PSO：$\omega$ 0.6-0.9、$c_1=c_2$≈2；
   - SA：初始温度要高（保证全局搜索）、降温慢、多次重启；
   - ACO：信息素挥发 $\rho$ 0.1-0.5；
   - DE：$F$ 0.5、$CR$ 0.9 附近起调。
4. **算法对比**：同一问题跑 2-3 种算法对比结果与收敛速度，论文中"模型求解"部分更有说服力。
5. **混合策略**：GA 全局搜索 + 局部搜索精化；SA 作 GA 变异算子——竞赛常用技巧。
6. **注意**：智能算法是**近似算法**，结果不保证全局最优——论文中说明参数设置与多次运行取最优，体现严谨。
