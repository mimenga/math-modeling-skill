# 进度跟踪协议（监控实时完成情况）

## progress.md 标准格式

```markdown
# 比赛进度跟踪
- 比赛/题目：{如 2025 高教杯 C 题 NIPT}
- 开始时间 / 截止时间
- 当前阶段：读题/数据/建模/检验/论文/提交
- 最后更新

## 子问题状态
| 子问题 | 状态 | 采用方法 | 关键结果 | 备注 |

## 完成清单
- [x] 问题拆解笔记
- [ ] 数据处理报告
...

## 下一步
- {1~3 项待办，按优先级}
```

## 更新时机

- 完成/推进任一子问题后立即更新；
- 每次会话结束更新"最后更新"时间戳；
- 用户要求汇报时读取并输出摘要。

## 汇报规则（四要素）

**当前阶段 + 已完成项/总项 + 剩余关键项 + 建议下一步**。对照时间表判断节奏：

- 落后 → 报告偏差 + 给"保底方案"（简化模型/砍非核心工作）
- 超前 → 建议投入检验、灵敏度、论文打磨

## 定时快照（可选）

用户要求"每天/每 X 小时汇报"时，创建定时任务：读取 progress.md 按汇报规则输出摘要。定时任务仅读取汇报，不擅自修改进度文件。

## 时间分配与危险信号

完整的六阶段时间占比、进度判断规则、危险信号与刚性底线，见同目录 `04_时间分配表.md`（避免重复维护）。
