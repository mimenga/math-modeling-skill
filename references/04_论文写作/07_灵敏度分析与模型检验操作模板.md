# 灵敏度分析与模型检验操作模板

> 来源：2023–2025 年 8 篇国一论文（A/C 题）深度剖析。本文是"怎么做、怎么写"的操作层模板；
> 检验与灵敏度在结构中的位置（独立成章 vs 按问分布）见 `03_论文结构模板.md`。

## 一、五种灵敏度范式（按题型选用，每种都经过国一论文验证）

### 范式 1：±5% 扰动型（通用首选，机理参数）
- **适用**：有明确物理/经济含义的参数（反射率、损耗率、价格系数、透射率）。
- **操作**：选 2–3 个关键参数 → 各扰动 ±5%（或 ±10%）→ 记录结果绝对变化量与相对变化率 → 横向比较各参数影响大小。
- **表格样式**：参数名 | 基准值 | −5%结果 | +5%结果 | 变化范围 | 相对变化率(%)。
- **结论句式**（三句走）：
  1. "将其变化程度定为 ±5%，即 0.875~0.966"（先定扰动区间）；
  2. "变化范围是 0.05027，即 5.027%"（给出量化结果）；
  3. "综上比较，镜面反射率对模型结果的影响要略大于大气投射效率，设计时应重点关注……"（横向排序 + 落建议）。
- **配图**：参数值-结果指标折线（多参数可画在同一张图对比斜率）。

### 范式 2：分布扰动型（随机因素/测量误差）
- **适用**：参数本质是随机的（速度、需求量受噪声影响）。
- **操作**：令参数服从 N(基准, σ²)，σ 取多档（如 0.02/0.05/0.1）→ 重跑 → 算结果与基准的均方差（MSD）或偏差指标。
- **结论句式**："当 σ 取 0.02~0.1 时，所有情形下的均方差均在 0.01 以内……模型具有较好的鲁棒性。"
- **配图**：不同 σ 下的结果分布或 MSD-σ 曲线。

### 范式 3：蒙特卡洛型（不确定性量化，数据题/统计题首选）
- **操作**：对关键随机变量抽样 N=1000 次 → 求解/预测 → 报告"中位数 + 95% 置信区间"。
- **配图**：均值线 + 95%CI 阴影带（结果随时间/参数变化的图，阴影即置信区间）——这是论文里最好看的灵敏度图。
- **结论句式**："蒙特卡洛模拟（N=1000）表明，最优时点的中位数为孕 16.2 周，95% 置信区间为 [15.1, 17.3]，区间宽度可接受。"

### 范式 4：对照实验型（几何/物理/仿真题）
- **操作**：把某个结构参数乘/加一个显著倍数（如镜间距 ×1.5）做对照 → 解释结果变化的物理机理。
- **要点**：必须配**机理解释**，不是只报数字。
- **结论句式**："镜间距增大至 1.5 倍后，阴影遮挡效率增大、截断效率减小。这是因为：……"

### 范式 5：极值情景型（优化/决策题）
- **操作**：对不确定的外生量（价格、需求）取最好/最坏/基准三情景重解 → 看目标值波动。
- **结论句式**："对销售价格做极值情景扰动，利润最大离散程度为 0.1273，方案仍具有良好稳定性。"

> 算法超参数（采样步长、种群规模、迭代上限）也算灵敏度对象："采样数 n∈[5,10] 扰动，三项关键指标变化均不显著，模型鲁棒。"

## 二、参数选择原则

1. 选 2–4 个**机理上确实影响结果**的参数，不选可有可无的；
2. 优先选题目给的、或自己估计引入误差的参数；
3. 优化题别忘了约束里的阈值型参数；启发式算法补一个算法超参数；
4. 每个参数的扰动方式（±5% / 分布 / 情景）在文中**明说依据**。

## 三、模型检验菜单（与灵敏度互补，按题取 2–4 项）

| 检验 | 做法 | 呈现方式 |
|---|---|---|
| 拟合优度 | RMSE / R² / MAPE / MRE | **写进结果表专列**，不止在文字里说 |
| 交叉验证 | k 折 CV 或留一，报相对误差与变异系数 | "相对误差 1.13%、CV=0.56%" |
| 显著性检验 | 回归系数 z/t 检验、LR 检验 | 表给"系数 | z | P>\|z\| | 95%CI"，正文解读 |
| 双方法互证 | 解析解 vs 数值解、两种算法/模型对比 | 差异 <1% 即结论可靠 |
| 反验 | 用已知数据/文献数据回代 | 与已知值对比表 |

## 四、"可靠性分析"小节模板（数据题/物理题推荐，直接套）

```
7.4 结果可靠性分析
  7.4.1 交叉验证   —— k 折/留一，相对误差、变异系数
  7.4.2 敏感性分析 —— 关键参数（如入射角）±0.1° 扰动，结果表
  7.4.3 蒙特卡洛模拟 —— N=1000，中位数 + 95%CI + 阴影图
结尾一句："上述三方面分析表明，算法结果具有较强的鲁棒性与可靠性。"
```

## 五、位置与篇幅

- **独立成章**（第六/八章）适合：几何物理题、优化题，全模型共用一套参数；
- **按问分布**（每问末尾"模型结果与误差分析"小节）适合：数据题各问方法不同、检验对象不同；
- 时间紧时至少保留"迭代收敛证据 + 一个参数的极值/±5% 扰动 + 拟合优度入表"（最低可行形态），
  完整范式留到正文时间充裕再补。
- 摘要收尾提及："对模型进行了验证与敏感性分析，结果表明模型对关键参数不敏感、具有较好鲁棒性。"
