# 摘要写作指南（占分最高）

## 结构模板（每段功能明确）

```
第一段（3-4行）：问题背景 + 我们做了什么
第二段（4-6行）：问题1 的方法 + 关键结果数字
第三段（4-6行）：问题2 的方法 + 关键结果数字
第四段（4-6行）：问题3 的方法 + 关键结果数字
第五段（3-4行）：问题4/开放问 的方法 + 结果
第六段（2-3行）：模型检验（灵敏度/误差）+ 一句话总结价值
```

## 高分摘要五要素（缺一不可）

1. **核心问题**：一两句话点明题目要解决什么（不抄原题）
2. **方法模型**：明确"针对问题 X 建立了 Y 模型、采用了 Z 方法"
3. **数据来源**：数据怎么来的、处理了什么
4. **具体结果**：**必须含数字**——拒绝"取得了较好的结果"
5. **模型评价**：灵敏度/误差指标 + 价值一句话

## 反面 vs 正面

> ❌ "本文首先分析了题目，然后建立了模型，最后给出了结论。"（等于没说）
>
> ✅ "针对蔬菜定价与补货问题，本文构建了'销量预测+动态定价+补货优化'三阶段模型：阶段一用随机森林预测各品类日销量（MAPE=8.3%）；阶段二基于销量弹性构建价格-需求模型；阶段三建立以利润最大化为目标、以损耗与货架期为约束的整数规划，求得各分店最优定价与补货量，总利润较原方案提升 12.6%，灵敏度分析表明模型在参数 ±10% 波动内保持稳定。"

## 摘要句式模板（背下来）

> 针对问题一，**观察数据发现**……，**因此建立**……模型，利用……算法求解，**得到**……，通过……检验，**误差为**……。

## 国一摘要的三个加分细节（2023–2025 获奖论文实证）

1. **创新概念加粗**：摘要里自创的模型名/方法名用粗体标出（如"**针对问题一**……建立**双色散复合模型**"），评委扫一眼就能抓住创新点；"针对问题X"本身也常加粗作为段落锚点。
2. **呼应交付要求**：题目要求提交结果文件（如 result1.xlsx）时，摘要显式写明"计算结果存于 result1.xlsx、result2.xlsx"，向评委表明交付完备。
3. 每问段末数字要成"三元组"落点（数量+效率+功率、时点+区间+准确率等），不要只落一个孤立数字。

## 写作时机

- **最后写**（模型和结果都定了才写）；
- 至少写 2 稿（初稿 D3 晚，精稿 D4 上午）；
- 三人一起审：写作手起草，建模手核数字，编程手核"是不是我们跑出来的"。
