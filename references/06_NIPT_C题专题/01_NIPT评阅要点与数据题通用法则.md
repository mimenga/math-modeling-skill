# NIPT 题评阅要点解析（2025C）

> 题目：基于真实 NIPT 数据：① 男胎 Y 染色体浓度与孕周、BMI 关系；② 按 BMI 分组确定各组最佳检测时点；③ 多因素优化分组与时点；④ 女胎异常判定方法。

## 官方总评方向（评委最看重）

> "着重关注**建模机制、风险指标和优化目标的合理性**、模型表述准确性、正常与异常样本**差异性分析**正确性，特别关注模型**适用性**、求解过程合理性和结果**真实性**。"

**注 2**：数据具有生物信息测量误差，**纯机器学习/大数据方法及其评价标准并不适合**——要"有机制、可解释、符合医学常识"。

## 四问逐条解读

### 问 1：Y 浓度与孕周、BMI 相关性
- ❌ 评委不要：直接 Pearson + 多元线性回归。
- ✅ 高分路径：Spearman 等非线性相关度量；**线性混合效应模型 LMM**（随机截距+孕周随机斜率，条件 R² 可达 0.83；不同队伍设定下亦有报 0.78 者——口径差异，非矛盾）；二次多项式、**自然样条回归** ns(GA,df=3)；配显著性检验 + 按 BMI 分组画浓度-孕周曲线。

### 问 2：按 BMI 分组 + 最佳时点
- ❌ 评委不要：K-means/层次聚类直接对 BMI 聚类（超半数队伍栽在这）。
- ✅ 高分路径：用**差异性指标**（组间 Y 浓度差异、达标概率差异）做**贪心切分**；风险指标结合"达标概率"与"终止妊娠风险"；在"达标概率最大化"与"时点尽早"间权衡；做敏感性分析。

### 问 3：多因素优化分组与时点
- ✅ 高分路径：贪心切分做 BMI 分组；组内最优时点用 **Cox 比例风险模型**（纳入多变量）+ 分段线性风险函数 + 自定义联合损失函数。

### 问 4：女胎异常判定
- ❌ 评委不要：直接 XGBoost/逻辑回归做二分类——"异常判断与普通分类有本质区别"。
- ✅ 高分路径：① 质控筛选（总读段数、比对率、重复率）② 样本分档（优/中/差）③ **双阈值三区判定**（0.995 判异常、0.99~0.995 灰区建议复检、<0.99 正常）④ 优良性分析（灵敏度/特异度/假阳性/假阴性 + 阈值医学依据）。

## 从 NIPT 提炼的"数据题通用应试法则"

1. 相关性分析别只做线性（Spearman/样条/多项式验证非线性）
2. 分组要有机制（用差异指标切分，别直接聚类）
3. 风险/目标刻画要合理（能从题目背景解释）
4. 异常判定≠分类（阈值 + 误判代价 + 三区判定）
5. 机器学习是工具不是答案
6. 每个问都有数字结果+图
7. 敏感性分析必做
8. **别为清洗而清洗**（评阅注 1：除空缺和输错外无需删补）

## 数据题通用框架（今年 C 题类似可直接套）

```
问1 规律挖掘：相关性（非线性）→ 拟合模型 → 显著性检验 → 图
问2 分组优化：差异指标切分 → 风险目标 → 最优决策 → 敏感性
问3 多因素升级：加协变量（Cox/多元回归）→ 联合损失
问4 判定模型：质控 → 分档 → 阈值设计 → 优良性
通用：有数字、有图、有解读、有敏感性、机制可解释
```
