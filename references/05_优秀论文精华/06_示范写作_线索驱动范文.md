# 06 示范写作：把"线索→模型"的规律用出来
### ——三段式范文 + 逐句点评（可直接模仿）

> 本节不是模板的空谈，而是**按国奖论文的逻辑规律现场写出的范文片段**，并逐句标注"这句为什么这样写"。建议对照 `03_模型选择依据与创新性.md` 阅读。

## 范文一：数据拟合类（模仿 2016C 电池放电题的逻辑）

### 原文片段（模拟）

> **问题一的分析。** 附件 1 给出了 20A–100A 九个电流强度下电池放电时间随电压的变化数据。为建立放电曲线模型，我们首先对原始数据进行了可视化。由图 1 可以看出，各电流强度下的放电曲线形态一致，均呈现"前期快速下降、中段近似线性、尾部趋于平缓"的特征；同时，曲线尾端（刚放电瞬间）存在一段明显偏离主趋势的过渡段，这与铅酸电池放电初期的钝化效应相符。
>
> **因此，在建模前我们剔除了各条曲线前 10% 的尾端数据，保留后 90% 的稳态放电数据。** 对处理后的数据分别做多项式拟合，发现二次多项式即可取得 0.9999 的拟合优度，继续增加次数对拟合精度几乎没有提升，故采用二次多项式模型：
>
>     T剩 = a(U − Um)² + b(U − Um) + c
>
> 其中 a、b、c 为待定系数，U 为电压，Um 为额定最低保护电压（9V）。

### 逐句点评

| 句子 | 点评 |
|------|------|
| "附件 1 给出了……数据" | 交代数据来源与内容（认知链起点） |
| "为建立放电曲线模型，我们首先对原始数据进行了可视化" | **明确"先看数据"的意图**，展示建模方法论 |
| "由图 1 可以看出……" | 用图作为证据，图文互证 |
| "这与铅酸电池放电初期的钝化效应相符" | 用物理知识解释数据现象（线索的可信度↑） |
| "**因此**，在建模前我们剔除了……前 10% 的数据" | **因果连接词 + 数据驱动的预处理决策** |
| "发现二次多项式即可取得 0.9999 的拟合优度，继续增加次数对拟合精度几乎没有提升" | **用数据对比支撑模型阶数选择**（为什么不用更高次） |
| "故采用二次多项式模型" | 模型选择有据可依 |

## 范文二：机理建模类（模仿 2018A 高温服装题的逻辑）

### 原文片段（模拟）

> **模型准备与物理分析。** 高温作业服由三层织物与一层空气间隙组成，环境热源为 75℃ 恒温热源，人体内部为 37℃ 恒温热源。热量的传递路径为：高温环境 → Ⅰ层 → Ⅱ层 → Ⅲ层 → 空气层 → 皮肤。
>
> 为确定热量传递方式，我们查阅相关文献[2]：当衣下空气层厚度不超过 6.4mm 时，空气间隙过窄，无法形成有效对流，此时热传递以热传导为主；同时，由于本问题温差范围较小（37–75℃），辐射传热能量远小于热传导，可忽略不计。
>
> **基于以上分析，本问题中热量仅通过热传导方式传递。** 又因各层织物均视为各向同性材料，温度仅在垂直于皮肤方向变化，故可建立一维热传导方程：
>
>     ρᵢcᵢ ∂Tᵢ/∂t = kᵢ ∂²Tᵢ/∂x²，i = 1,2,3,4
>
> 其中 ρᵢ、cᵢ、kᵢ 分别为第 i 层介质的密度、比热容与导热系数。由于上述方程组难以求得解析解，我们采用有限差分法中的后向欧拉格式对其进行数值求解。

### 逐句点评

| 句子 | 点评 |
|------|------|
| "热量的传递路径为……" | 先画物理过程（示意图会在正文出现） |
| "为确定热量传递方式，我们查阅相关文献[2]" | **用文献支撑物理假设**（线索来源多元化） |
| "当衣下空气层厚度不超过 6.4mm 时……可忽略不计" | 逐条排除其他传热方式，逻辑严密 |
| "**基于以上分析**，本问题中热量仅通过热传导方式传递" | 假设建立在推理之上而非拍脑袋 |
| "故可建立一维热传导方程" | 模型选择与假设一一对应 |
| "由于上述方程组难以求得解析解，我们采用有限差分法" | **求解方法选择也给出理由** |

## 范文三：优化决策类（模仿 2019C 机场出租车题的逻辑）

### 原文片段（模拟）

> **问题二的分析。** 本问要求确定上车点数量使乘车效率最高。从系统角度看，上车点数量过少会导致乘客排队过长，过多则增加管理与安全成本，因此存在一个最优数量。这一问题的特点是：乘车过程受航班到达的随机性、出租车的随机到达率等因素影响，难以用解析模型精确刻画。
>
> **考虑到系统的随机性，我们采用计算机模拟（蒙特卡洛）方法**：首先根据实际数据拟合乘客到达率与出租车到达率的分布，制定乘车区运行规则，然后对不同上车点数量方案（4、6、8、10）各模拟 10000 次，统计乘客平均等待时间与出租车平均等待时间，以总乘车效率最大为目标确定最优方案。
>
> 模拟结果（见表 X）表明：当上车点数量为 4 时，乘客平均用时 1.9 分钟，出租车平均用时 19.9 分钟，综合效率最高；当人车数量相当时，8 个上车点效率更优。**进一步地，我们对模拟截止时间 T₀ 进行了敏感性分析，发现 T₀ 超过 40 分钟后乘车效率趋于稳定，说明模拟参数的选取是稳健的。**

### 逐句点评

| 句子 | 点评 |
|------|------|
| "上车点数量过少会导致……过多则增加……" | 先做定性分析，论证"最优存在" |
| "难以用解析模型精确刻画" | **交代为什么不用解析模型**（否定式论证） |
| "**考虑到系统的随机性，我们采用计算机模拟方法**" | 线索→方法选择的显式表达 |
| "根据实际数据拟合……分布" | 模拟参数有数据依据 |
| "各模拟 10000 次" | 交代模拟规模（可信度） |
| "模拟结果（见表 X）表明……" | 结果带表格、带数字 |
| "**进一步地**，我们对……进行了敏感性分析……说明……是稳健的" | 检验环节 + 逻辑闭环 |

## 三、从三段范文中提炼的"万能写作动作"

1. **先给证据，再给结论**：任何"因此我们用了 X 模型"之前，必有一句"因为看到了 Y"。
2. **用图/表当证人**：数据观察用图证明，结果汇报用表证明。
3. **否定式论证增加说服力**："解析模型难以刻画""继续增加次数无提升"——说明你**比较过**，不是只会一种方法。
4. **检验是论证的一部分**：灵敏度/稳定性分析放在结论之后，让"结论可靠"成立。
5. **每段第一句承接上一段**：使用"基于以上分析""进一步地""为此"等过渡。

## 四、练习建议

- 拿一份近年真题（如 2024C 题），练习为每个问题写"问题分析"段，强制自己使用句式：
  **"观察数据发现……，因此采用……模型"**。
- 找一篇你写过的旧论文，逐段检查：**每个模型出现前，是否有线索句？** 没有的补上。
- 用 `04_论文写作/02_摘要写作指南.md` 的句式模板重写一次摘要，确保每问都有方法+算法+数字。
