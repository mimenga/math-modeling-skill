# 04 国赛论文写作指南
### ——可复用的写作模板与逻辑范式（含 AI 写作适配版）

> 本指南基于 8 篇国奖论文的共性规律提炼而成，可直接用于实战写作。特别针对 AI 写作的弱点做了适配：**每个模型必须由数据线索引出，逻辑环环相扣，杜绝机器学习堆砌。**

---

## 一、写作全流程（按时间线）

```
第 1 步 读题拆题（1–2h）
   ├─ 逐字读题，圈出所有"已知条件、数据文件、要求输出" 
   ├─ 判断题型：机理/几何/数据/优化/评价/排队
   ├─ 列问题清单：问题1~N 各是什么类型、各需要什么输出
   └─ 产出：问题分析草稿（这是论文的逻辑骨架）

第 2 步 数据探索（2–3h）★关键★
   ├─ 读入所有附件，画图（曲线、散点、分布、相关性）
   ├─ 记录每个数据特征："我看到了什么"
   │   例：曲线尾部有钝化段 / 数据与X呈线性 / 存在异常值
   ├─ 决定每个问题用什么模型（由特征决定！）
   └─ 产出：数据观察笔记（写作时转成"线索"段落）

第 3 步 建模求解（大部分时间）
   ├─ 按"线索→模型"逐问建模，每问完成小闭环
   ├─ 保存所有中间结果：表格、图、误差指标
   └─ 产出：模型 + 结果 + 检验（每个数字都要留档）

第 4 步 检验与灵敏度（必须做）
   ├─ 用已知数据/文献反验
   ├─ 误差指标：R²、MRE、相对误差、误差限
   └─ 灵敏度/稳定性：参数扰动、加噪声、对比算法

第 5 步 排版成文（最后集中写，但摘要要早起草）
   ├─ 先写正文（问题分析→模型→结果）
   ├─ 再写摘要（浓缩正文，逐问给数字）
   └─ 补图表、附录、参考文献
```

## 二、论文结构模板（可直接套用）

```
标题：XXX 的模型研究 / 基于XX模型的XXX
─────────────────────────────
摘要（单独一页，400-600字）
  开头段：研究什么问题 + 总体思路
  问题一：建立了XX模型，用XX算法求解，得到XX结果（带误差）
  问题二：……（同上句式）
  ……
  关键词：3-5个（模型+算法+核心概念）
─────────────────────────────
1 问题重述
  1.1 问题背景（可用题目原文改写，2-3句即可）
  1.2 问题的相关信息（列出所有已知条件/数据/公式）
  1.3 需解决的问题（逐条列出，可与原题一一对应）
2 问题分析（★逻辑枢纽★）
  2.1 问题一的分析：类型→难点→思路→产出
  2.2 问题二的分析：……
  （本题为机理题时，可在分析前先讲物理/几何背景）
3 模型假设（3–5 条【硬约束】，每条给出理由，可用[文献]支撑）
4 符号说明（表格：符号 | 含义 | 单位）
5 数据处理（可选但推荐）
  5.1 数据来源与说明
  5.2 数据特征观察（★写"从图中可以看出…"★）
  5.3 数据预处理（清洗、变换、归一化、删减，说明依据）
6 模型的建立与求解
  6.1 问题一的模型
    6.1.1 模型的准备/物理背景（工具先行）
    6.1.2 模型的建立（线索→公式推导→完整模型）
    6.1.3 求解算法（步骤STEP + 流程图）
    6.1.4 求解结果（表格+图+解读）
    6.1.5 模型检验（误差/对照）
    6.1.6 结果分析
  6.2 问题二的模型（同构）
  ……
7 模型的检验与灵敏度分析
  7.1 误差分析（汇总各问误差指标）
  7.2 灵敏度分析（参数扰动对结果的影响）
  7.3 稳定性分析（加噪声/换参数区间/对比算法）
8 模型的评价、改进与推广
  8.1 模型的优点（3-4条，具体）
  8.2 模型的缺点（2-3条，真诚）
  8.3 模型的改进（针对缺点）
  8.4 模型的推广（可迁移到其他场景）
9 参考文献（正文[1][2]标注，格式规范）
10 附录（程序、大表格、详细推导）
─────────────────────────────
```

## 三、逻辑衔接句式库（AI 写作时直接调用）

### 1. 数据线索 → 模型选择（核心句式，务必使用）
- "观察图 X 发现，……呈现明显的……趋势，**因此**采用……模型"
- "由附件数据可知……，**这暗示**……，**据此**建立……模型"
- "查阅文献[2]得知……，**故**在本问题中只考虑……"
- "从图中可以看出，9 条曲线的拟合度 R² 都高达 0.9999，**说明**二次多项式能够很好地刻画……"

### 2. 问题类型判断
- "该问题是一个**单目标最优化问题**，决策变量为……，目标函数为……"
- "本题的**难点在于**……，为克服这一难点，本文……"
- "这是一个**带精度检验的拟合问题**"

### 3. 模型内部推进
- "**首先**……**其次**……**最后**……"
- "基于上述分析，**联立**式(1)(2)(3)可得……"
- "由于方程(5)无解析解，**故**采用数值方法求解"
- "将式(8)代入式(6)，**化简**得……"

### 4. 检验与评价
- "模型检验结果**表明**：……误差仅为……，在可接受范围内"
- "对参数 X 进行灵敏度分析，**结果表明**：当 X 变化 ±10% 时，结果变化……，说明模型对 X 不敏感"
- "本文模型的**优点**是……，**不足**是……，**改进方向**是……"

### 5. 承接过渡（避免段落断裂）
- "为进一步求解……，需要先确定……"
- "基于问题一建立的模型，问题二在……基础上进一步考虑……"
- "综合以上分析，可建立如下数学模型"

## 四、摘要写作模板（逐问给数字）

```
【开头】本文针对[题目核心问题]建立了数学模型，研究了[研究对象]的[核心规律]。

【问题一】针对问题一，[一句话线索]，建立了[模型名]，利用[算法名]求解，
        得到[关键结果1]；通过[检验方法]验证，[误差指标]=[数值]。

【问题二】针对问题二，在问题一基础上考虑[新增因素]，建立[模型名]，
        求得[关键结果2]，并绘制了[图表]。

【问题三】针对问题三，建立了[模型名]（目标函数：…；约束：…），
        通过[算法]求解，得到最优[决策]=[数值]，此时[结果指标]=[数值]。

【结尾】最后对模型进行了[灵敏度/稳定性]分析，验证了模型的可靠性。
关键词：模型1；算法1；模型2；概念1；概念2
```

**写作纪律**：
- 每问 ≤2 句：1 句方法 + 1 句结果（必须带数字）；
- 全文 400–600 字，一页之内；
- 摘要中**不出现**未在正文交代的内容；
- 数字精确到该题的合理有效位数（如 12:12、3.84m、R²=0.9999）。

## 五、避坑清单（AI 写国赛论文的常见雷区）

| 雷区 | 为什么致命 | 正确做法 |
|------|-----------|---------|
| 模型凭空出现 | 评阅人看不到"为什么选它" | 每个模型前写"线索"段 |
| 堆砌机器学习 | 不可解释、不可检验、评审反感 | 经典方法为主线，ML 仅对照 |
| 只写方法不写结果 | 摘要没数字 = 没干货 | 每问给出具体数字结果 |
| 空洞评价"效果较好" | 无量化支撑 | 带 R²/误差/百分比 |
| 假设无理由 | 显得随意 | 每条假设给物理/文献依据 |
| 图表无解读 | 图成为装饰 | 图后必有"从图中可以看出…" |
| 章节断裂 | 逻辑不连贯 | 段首用因果承接词 |
| 正文超长 | 国赛限 25 页 | 细节进附录 |
| 无检验环节 | 模型可信度存疑 | 必做误差+对照检验 |
| 无灵敏度分析 | 显得考虑不周 | 至少做 1 个参数的灵敏度 |

## 六、非机器学习建模工具箱（按需求速查）

| 需求 | 推荐经典模型 | 常见于 |

| 拟合/预测曲线 | 多项式拟合、指数/对数拟合、分段拟合 | 2016C、2015A |

## 七、AI 辅助写作工作流（推荐）

1. **让 AI 先做数据探索**：画图、计算相关性、找规律 → 人工确认"线索"；
2. **人工确定模型路线**（最重要的一步，AI 可给建议但由你拍板）：哪些线索对应哪些模型；
3. **让 AI 按模板写初稿**：明确告诉它"每个模型出现前必须写线索段落"；
4. **人工审查逻辑链**：逐段问"这一段为什么存在？承上启下吗？"；
5. **让 AI 补检验与灵敏度**（这是 AI 最擅长的查漏环节）；
6. **人工润色图表与摘要**。

> ⚠️ 用 AI 写作时，务必在提示词中强调：**"不使用机器学习/神经网络作为主模型；每个模型引入前需说明数据或文献线索；结果必须带数值；每段用因果逻辑衔接。"**

## 八、写作节奏建议（74 小时冲刺版）

| 时间段 | 任务 |
|--------|------|
| 第 1 天上午 | 选题、读题、数据探索、问题分析定稿 |
| 第 1 天下午-第 2 天上午 | 逐问建模求解（先保 2 问完整） |
| 第 2 天下午 | 全部问题求解 + 检验 + 灵敏度 |
| 第 2 天晚上 | 正文排版成文（含图表） |
| 第 3 天上午 | 摘要、模型评价、参考文献、附录 |
| 第 3 天下午 | 全文逻辑审查、数字核对、图表补漏 |
| 交稿前 2h | 只做格式检查（三线表、图表编号、页数） |
