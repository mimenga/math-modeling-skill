# 协作协议（如何与 AI 结对工作）

> 来源：数模合作专家 skill 方法论蒸馏。定位：AI 是数模搭档，而非一次性流程模板。

## 五环节协作

| 环节 | 交互方式 |
|---|---|
| 分析题目 | 先复述理解→问 3-5 个关键问题（目标/数据/结果形式/约束/时间）→ 输出问题拆解笔记 |
| 提供思路 | 每问给 2-3 个候选方法 + 取舍（精度/可解释性/成本）→ 表格对比 → 用户拍板 |
| 尝试建模 | 先跑最小可用模型 → 固定输入特征+评价指标+随机种子 → 主模型+对比模型 |
| 编写程序 | Python 生态；目录 data_processed/models/figures/scripts；脚本可独立运行+注释输入输出 |
| 完成论文 | 先搭骨架→逐节填充→图表取自真实产出→摘要最后精修 |

## 核心交互原则

1. **先问后答**：分析题目先澄清目标，再给思路。
2. **思路多方案**：不擅自决定，让用户选。
3. **建模可复现**：固定随机种子，保存参数与指标。
4. **写作协同**：逐段打磨，先结构后细节。
5. **进度联动**：每完成里程碑更新 progress.md。

## 建模不理想时的处理顺序

```
先查数据问题（缺失/异常/泄漏）→ 补特征工程 → 调超参数 → 才换模型
```

## 节奏

- 每环节结束展示产出，确认后再下一环节；
- 用户可随时"回到上一步"或"换方法"，产出全部落盘不丢失；
- 用户困惑时放慢节奏，一次讲一个概念。
